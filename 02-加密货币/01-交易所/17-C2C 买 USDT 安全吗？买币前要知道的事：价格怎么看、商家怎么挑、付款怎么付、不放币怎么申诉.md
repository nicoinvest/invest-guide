## 一、C2C 买币，平台是怎么担保的？

C2C 买币的时候，你是付钱的一方，商家是放币的一方。整个流程是这样的：

1. 你下单买入，**商家的 USDT 被平台冻结**，商家自己也动不了；
2. 你按订单上的收款信息，把人民币转给商家；
3. 你在订单里点「我已付款」；
4. 商家确认收到钱，点「放币」，USDT 从冻结状态转到你的账户。

![C2C 买币时平台怎么担保：下单后商家的 USDT 被冻结，你付款并点我已付款，商家确认收款后放币](https://invest-nav.com/tutorial-content/new-2026-11-01/usdt-c2c-buy-guide/fig-01.webp)

关键在第 1 步：**你下单的那一刻，商家要卖给你的 USDT 已经被平台锁住了**。只要你真的付了款，商家就拿不回这些币，就算他不放币，你也可以申诉，由平台客服核实后强制放币。

所以 C2C 买币最大的风险，不是「付了钱拿不到币」，而是**你自己做错了某一步，让平台没法替你主张**，比如付错了账户、在平台外私下交易。

## 二、价格为什么和汇率不一样？

C2C 上的 USDT 价格是商家自己报的，一般会贴着美元兑人民币的汇率上下浮动：

- **买入价格通常略高于汇率**，比如汇率 7.13 的时候，C2C 买入价可能在 7.15–7.20；
- 行情火热、大家都在抢着买币的时候，买入价会明显高于汇率，这叫**溢价**；
- 行情冷清的时候，价格会贴近甚至低于汇率。

C2C 本身不收手续费，商家赚的就是买卖之间的差价。几个靠谱商家之间的价格一般只差几分钱：买 1 万元的 USDT，价格差 0.02，大约就是 28 元人民币。**为了这几十块钱去选一个数据很差的新商家，不值得。**

## 三、商家怎么挑？

商家列表里，每个商家都会显示几项数据，重点看这些：

| 看什么 | 怎么判断 |
| --- | --- |
| 认证商家标识 | 优先选，认证商家在平台交了保证金，资金来源也经过审核 |
| 成交单数 | 几千单以上比较稳 |
| 完成率 | 98% 以上 |
| 平均放币时间 | 越短越好，说明商家在线、处理快 |
| 交易条款 | 下单前点开看，比如「只接受本人实名付款」「单笔最低 500 元」 |

还有一个容易忽略的点：**看商家支持哪些付款方式**。你要用银行卡付，就别选只收支付宝的商家，下单以后才发现付不了，只能取消订单，取消次数多了会被限制当天交易。

## 四、付款：这一步决定了你的钱安不安全

### 1. 只按订单页面上的收款信息付款

下单以后，订单页面会显示商家的收款账户：姓名、银行卡号或支付宝账号。**只认这里显示的信息**，商家在聊天里发来的「另一个账户」「临时换个卡」，一律不要付。

付到订单以外的账户，平台就没法帮你核实，等于这笔钱和这个订单没有关系了。

### 2. 用你本人实名的账户付款

付款的银行卡或支付宝，必须是**你自己的、和交易所实名一致的账户**。用家人、朋友的卡付款，商家看到付款人和下单人名字对不上，按规则是可以拒绝放币的，而且这本身就违反平台规则。

### 3. 金额要和订单完全一致

订单金额是多少就付多少，不要凑整、不要多付或少付。金额对不上，商家可能不放币，后面申诉也会麻烦。

![付款时核对三件事：只付订单上的收款账户、用本人实名账户付款、金额和订单完全一致](https://invest-nav.com/tutorial-content/new-2026-11-01/usdt-c2c-buy-guide/fig-02.webp)

### 4. 付完钱再点「我已付款」

「我已付款」这个按钮，只能在**钱真的转出去以后**再点。没付钱先点，是违反平台规则的，商家可以申诉，你的账户可能被限制 C2C 交易。

付完款以后，把银行或支付宝的**付款成功截图**保存下来，万一后面要申诉，这就是最重要的证据。

### 5. 付了款，千万不要取消订单

付完钱以后，如果商家说「我这边出了点问题，你先取消订单，我把钱退给你」，**不要取消**。订单一取消，商家冻结的 USDT 就解冻了，你的钱能不能退回来，全看商家的良心，平台不再介入。

遇到这种情况，直接点「申诉」。

## 五、付了款，商家不放币怎么办？

先别慌，按下面的顺序处理：

1. **先等一等**：商家可能在核对到账，大部分商家几分钟内就会放币；
2. **在订单聊天里提醒**：发一句「已付款，请查收并放币」，附上付款截图；
3. **超过放币时限还没放，点「申诉」**：申诉原因选「已付款，对方未放币」，上传付款成功的截图或银行流水；
4. **等客服处理**：客服会联系商家核实，确认你确实付了款以后，会强制放币。

整个申诉期间，商家的 USDT 一直是冻结状态，他拿不走。只要你是按订单信息、用本人账户付的款，申诉基本都能解决。

| 遇到的情况 | 怎么做 |
| --- | --- |
| 商家超时没放币 | 订单里点「申诉」，上传付款截图 |
| 商家说没收到钱 | 提供银行或支付宝的付款记录，申诉 |
| 商家让你取消订单、说退钱 | 不取消，申诉 |
| 商家让你加微信、QQ 私聊 | 拒绝，所有沟通都在订单聊天里 |
| 商家让你再付一笔「验证」 | 骗局，拒绝并申诉 |

## 六、买币的一方，也要注意资金安全

很多人以为冻卡只发生在卖币的人身上，其实买币的一方也要注意：

- 如果商家本身有问题，他用来收款的账户被冻结，你付过去的钱可能被卡住，或者在银行的协查名单里出现你的名字；
- 少数骗子会冒充买家或商家，利用 C2C 转移非法资金，你和他有过资金往来，就可能被问询。

降低这类风险的办法和卖币时类似：

1. **只和认证商家交易**，成交单数多、完成率高的优先；
2. **大额拆成几笔**，分给几个不同的靠谱商家；
3. **用一张专门用来买币的卡**，别用工资卡、房贷卡；
4. **保留每一笔订单的截图和付款记录**，被问到资金去向时，这些就是你的证明。
