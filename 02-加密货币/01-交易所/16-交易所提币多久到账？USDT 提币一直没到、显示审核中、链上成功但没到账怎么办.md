# 交易所提币多久到账？USDT 提币一直没到、显示审核中、链上成功但没到账怎么办

作者：[Nico 投资有道](https://www.youtube.com/@NicoGrowthz) · [投资导航网页版](https://invest-nav.com/tutorials/exchanges/text/crypto-withdrawal-not-arrived/) · [返回本分类](./README.md)

提币已经半个小时了，钱还没到？提币记录里一直显示「审核中」？区块浏览器里明明显示成功了，收款的交易所却怎么都看不到这笔钱？

提币不到账是最让人心慌的情况之一，几千几万 USDT 不知道在哪里，很多人第一反应就是到处找「客服」，结果又被骗了一次。其实提币的每一步都能查到状态，只要知道卡在哪里，就知道该等、该查，还是该找谁。

今天这篇教程，我会把提币一般多久到账、不到账的几种情况分别是什么原因、该怎么处理一次性讲清楚，带你一步一步排查，避开着急时最容易踩的坑。

那我们话不多说，尽快开始今天的内容。

## 一、正常情况下，多久到账？

提币到账的时间，主要取决于你选的网络：

| 网络 | 一般到账时间 |
| --- | --- |
| BEP20 | 1 分钟左右 |
| Solana | 几十秒到 1 分钟 |
| TRC20 | 1–3 分钟 |
| APTOS | 1–3 分钟 |
| ERC20 | 3–10 分钟，拥堵时更久 |

这里的时间是从**交易所把币发出去**开始算的。在这之前，交易所还要先做风控审核，大部分时候几秒钟就过了，少数时候会久一些。

所以，**超过 30 分钟还没到账，才需要开始排查**。网络选的是什么、各网络有什么区别，可以先看[提币网络怎么选](<./28-USDT 提币选哪个网络？TRC20、ERC20、BSC 有什么区别，转错链、漏填 Memo 怎么办.md>)。

## 二、先看卡在哪一步

一笔提币，要经过三个环节：

1. **发送方审核**：你提交提币，发送方交易所审核；
2. **链上转账**：审核通过，币发到区块链上，等区块确认；
3. **收款方入账**：收款方交易所或钱包检测到这笔转账，记到你的账户上。

打开发送方的**提币记录**，看这笔提币的状态，就知道卡在哪一步：

| 提币记录里的状态 | 卡在哪里 | 看下面第几节 |
| --- | --- | --- |
| 审核中、处理中，没有交易哈希 | 第 1 步 | 第三节 |
| 已完成，有交易哈希 | 第 2 步或第 3 步 | 第四节 |
| 失败、已取消 | 提币没发出去 | 币会退回你的账户，看一下失败原因 |

![没到账先看卡在哪一步：发送方审核、链上转账、收款方入账](https://invest-nav.com/tutorial-content/new-2026-11-01/crypto-withdrawal-not-arrived/fig-01.webp)

## 三、一直显示「审核中」

提币卡在审核阶段，还没上链，说明币还在发送方交易所里，**是安全的**。常见原因有：

| 原因 | 要等多久 |
| --- | --- |
| 第一次提币，或者第一次往这个地址提币 | 几分钟到几小时 |
| 刚改过密码、手机号、谷歌验证器 | 很多交易所会锁定提币 24 小时左右 |
| 金额比平时大很多 | 可能需要人工审核，几小时 |
| 刚通过 C2C 买入的币 | 部分交易所有一段时间的提币限制 |
| 交易所在维护这个网络的钱包 | 提币页面一般会有公告，维护完成后自动处理 |

这种情况，在发送方 App 的**在线客服**里问一下审核进度就行。急着用钱的话，别在当天改安全设置，大额提币提前一天操作。

## 四、已经有交易哈希了，但还没到账

有了交易哈希（TxID），说明币已经从发送方发出去了。下一步是**去区块浏览器里查这笔转账**：

| 网络 | 区块浏览器 |
| --- | --- |
| TRC20 | tronscan.org |
| BEP20 | bscscan.com |
| ERC20 | etherscan.io |
| Solana | solscan.io |
| APTOS | explorer.aptoslabs.com |

把交易哈希粘贴到搜索框，看三处：**状态**、**收款地址**、**金额和代币**。根据结果，分几种情况：

![区块浏览器里看三处：状态是否成功、收款地址对不对、代币和数量对不对](https://invest-nav.com/tutorial-content/new-2026-11-01/crypto-withdrawal-not-arrived/fig-02.webp)

### 1. 状态是 Pending（等待中）

链上还在排队，一般是网络拥堵，最常见于 ERC20。耐心等就行，通常几分钟到几十分钟会完成。

### 2. 状态是成功，收款地址也对，但收款方还没入账

这种情况最常见，原因一般是：

- **收款方在等区块确认数**：每家交易所对每个网络要求的确认数不一样，链上成功以后还要再等一会儿；
- **收款方的这个网络正在维护**：充值会延迟入账，维护结束后自动到账；
- **转的币种不对**：比如你转的是 USDC，收款地址是 USDT 的充值地址。同一个网络上的 USDC 和 USDT 地址往往是同一个，但交易所可能不会自动入账。

等了一个小时还没到，就带着交易哈希去找**收款方**的客服，让他们查。

### 3. 状态是成功，但收款地址不对

说明地址填错了，币转给了一个陌生地址。区块链转账是**不可撤回的**，没有任何人能帮你追回。这种情况，只能接受损失，下次一定先小额试转。

### 4. 状态是失败

链上转账失败，币一般会退回发送方，或者根本没发出去。回到发送方的资产里看一下，有疑问找发送方客服。

## 五、选错网络、漏填 Memo，还能找回吗？

### 1. 漏填或填错 Memo

收款方是交易所，而且充值页面要求填 Memo（标签），你却没填或填错了。这种情况**币到了交易所的地址**，只是交易所不知道该记给谁。

处理办法：联系**收款交易所**的客服，申请「未入账充值找回」，一般要提供：

- 交易哈希；
- 币种、网络、金额；
- 你在收款交易所的 UID；
- 有的还要发送方的提币记录截图。

大多数情况能找回，但要等几天，有的交易所会收一笔处理费。

### 2. 选错了网络

| 情况 | 能不能找回 |
| --- | --- |
| 两个网络的地址格式一样（比如 ERC20 和 BEP20 都是 0x 开头），收款方是你自己的钱包 | 能，在钱包里切换到你实际转的那个网络就能看到 |
| 地址格式一样，收款方是交易所 | 有可能，联系收款交易所的客服申请找回 |
| 收款方根本不支持你转的那个网络 | 看收款方能不能人工处理，不保证 |
| 地址格式完全不同（比如 T 开头的波场地址），提币页面一般会直接报错 | 一般转不出去 |

## 六、着急的时候，最容易被骗

提币不到账、心里着急的时候，是骗子最喜欢下手的时候：

- 在社交平台、群里发帖求助，马上就会有「客服」私信你，说能帮你「加急处理」；
- 搜索引擎里搜「欧易客服电话」「币安人工客服」，排在前面的往往是假的；
- 假客服会让你下载远程控制软件、提供验证码，或者让你「先转一笔保证金解冻」。

**真正的客服只在 App 里的「帮助中心」或「在线客服」里**。任何主动联系你、让你转账、要你验证码的人，都是骗子。更多骗局套路可以看[币圈防骗指南](../02-加密货币基础/14-币圈常见骗局有哪些？钓鱼、假客服与貔貅盘防骗指南.md)。

## 七、怎么避免下次再遇到

1. **新地址、新网络，先小额试转**，到账了再转大额；
2. **在收款方先选网络，再复制地址**，发送方选一样的网络；
3. **收款方显示了 Memo，就一定要填**；
4. **常用地址加进提币白名单**，以后直接选，不用每次粘贴；
5. **大额提币提前一天**，不要在急着用钱的当天操作；
6. **改安全设置之后，留出 24 小时**再提币。

## 写在最后

提币不到账，先别慌，按「发送方审核 → 链上转账 → 收款方入账」三步排查：没有交易哈希就找发送方，有交易哈希就去区块浏览器查，链上成功了还没到就找收款方。

绝大多数情况，要么是在审核、要么是在等确认，等一等就到了。真正找不回来的，只有地址填错这一种，所以每一笔新地址的转账，都值得先试一笔小的。
