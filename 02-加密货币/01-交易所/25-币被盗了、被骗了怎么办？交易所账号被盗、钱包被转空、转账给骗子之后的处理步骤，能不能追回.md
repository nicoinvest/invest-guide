# 币被盗了、被骗了怎么办？交易所账号被盗、钱包被转空、转账给骗子之后的处理步骤，能不能追回

作者：[Nico 投资有道](https://www.youtube.com/@NicoGrowthz) · [投资导航网页版](https://invest-nav.com/tutorials/exchanges/text/crypto-stolen-what-to-do/) · [返回本分类](./README.md)

打开钱包，发现里面的 USDT 全没了？交易所账户里的币被人提走了，自己根本没操作过？被所谓的「投资导师」骗着转了一大笔 USDT，现在才发现是骗局？

遇到这种事，第一反应往往是慌，然后到处搜「币被盗了怎么追回」，结果又遇到一群声称能「黑客追回」的人，再被骗一次。其实币被盗、被骗以后，**能做的事情是有顺序的**：先止损，保住剩下的；再留证据、查去向；最后报警、联系交易所。顺序对了，才有机会挽回一部分。

今天这篇教程，我会把币被盗、被骗以后第一时间要做的事一次性讲清楚，按不同的情况一步一步带你处理，再告诉大家，什么情况下还有机会追回，以及处理过程中最容易踩的坑。

那我们话不多说，尽快开始今天的内容。

## 一、先判断是哪一种情况

不同的情况，止损的方法完全不一样。先对照一下：

| 情况 | 典型表现 | 问题出在哪 |
| --- | --- | --- |
| ① 交易所账号被盗 | 交易所里的币被提走，提币记录里有你没操作过的记录 | 密码、验证码、邮箱泄露 |
| ② 钱包私钥或助记词泄露 | 钱包里所有的币，在很短时间内被转到同一个陌生地址 | 助记词被人拿到了 |
| ③ 授权被盗 | 只有某一种币被转走，比如 USDT 没了，ETH 还在 | 给恶意合约授过权，或者签过钓鱼签名 |
| ④ 被骗转账 | 是你自己转出去的，转给了「导师」「客服」「平台」 | 被诈骗 |

![币被盗、被骗的 4 种情况：交易所账号被盗、助记词泄露、授权被盗、被骗转账，问题分别出在哪里](https://invest-nav.com/tutorial-content/new-2026-11-01/crypto-stolen-what-to-do/fig-01.webp)

## 二、第一时间止损：保住剩下的

### ① 交易所账号被盗

1. **马上冻结账户**：四家大交易所的 App 和网页里，安全中心都有「冻结账户」或「禁用账户」的功能，冻结以后谁都不能交易和提币；找不到的话，立刻联系 App 里的在线客服，要求冻结；
2. **改邮箱密码**：交易所账号被盗，很多时候是邮箱先被盗了；
3. **在客服那里说明情况**：告诉客服哪几笔提币不是你操作的，提供提币的时间、金额、地址；
4. 等账户解冻以后，**重新设置所有安全项**：登录密码、资金密码、谷歌验证器、防钓鱼码。

### ② 钱包助记词泄露

1. **马上新建一个钱包**：注意是**重新创建**一个新钱包，生成新的助记词，不是导入旧的；
2. **把旧钱包里剩下的币，全部转到新钱包**：骗子有时候会先转走大头，留一些小币种，赶在他之前转走；
3. **旧钱包从此不再使用**：以后也不要往里面转任何币。

需要注意一个情况：如果旧钱包里已经没有 Gas 了，你往里面转 Gas，骗子的机器人可能会在几秒钟内把 Gas 抢走。这种情况下不要反复往里面转钱。

### ③ 授权被盗

1. **马上取消所有可疑授权**：用 Revoke.cash 或者区块浏览器的授权检查工具，具体方法看[钱包授权怎么查看和取消](../04-Web3钱包/09-钱包授权是什么？无限授权有多危险，怎么查看和取消授权，签名前要看清哪几点.md)；
2. **把剩下的币转到一个新钱包**：不确定还有没有别的授权或者签名漏掉了，最稳妥的是直接换钱包。

### ④ 被骗转账

1. **立刻停止继续转账**：骗局最常见的套路是「再交一笔保证金、手续费、税费就能提现」，一分钱都不要再转；
2. **不要删聊天记录**：这些都是证据；
3. **不要被对方的「最后一次机会」催着做决定**。

## 三、保存证据

不管是哪种情况，都要把下面这些整理好，后面联系交易所、报警都会用到：

| 证据 | 怎么拿 |
| --- | --- |
| 交易哈希（TxID） | 钱包或交易所的转账记录里点开每一笔，复制交易哈希 |
| 你的地址、对方的地址 | 转账详情里都有 |
| 时间、币种、金额 | 截图转账记录 |
| 聊天记录 | 微信、电报、WhatsApp 等，完整截图或导出，包括对方的账号 |
| 骗局网站或 App | 网址、App 名称、截图 |
| 交易所账户信息 | 你的 UID、注册邮箱 |

## 四、追踪币流向了哪里

拿着交易哈希，去对应的区块浏览器里查：

| 网络 | 区块浏览器 |
| --- | --- |
| 以太坊 | etherscan.io |
| BSC | bscscan.com |
| 波场 TRC20 | tronscan.org |
| Solana | solscan.io |

点开被盗的那一笔，看收款地址，再点进这个地址，看它后来又把币转到了哪里。顺着往下追，关注一个关键信息：**币有没有流进交易所**。

区块浏览器会给很多交易所的地址打上标签，比如「Binance」「OKX」「Bybit」。如果你看到被盗的币，最后流进了一个带交易所标签的地址，这是**最有机会追回的情况**，因为交易所知道这个充值地址属于哪个实名用户，在收到执法机构的协查要求后，可以冻结这个账户里的资金。

![追踪资金去向：从被盗交易出发，顺着收款地址往下看，币流进带交易所标签的地址时最有机会冻结](https://invest-nav.com/tutorial-content/new-2026-11-01/crypto-stolen-what-to-do/fig-02.webp)

### 哪些情况有机会追回？

| 情况 | 追回的可能性 |
| --- | --- |
| 币流进了大交易所，而且你报案很快 | 相对高，交易所可以在协查后冻结 |
| 被盗的是 USDT，还停留在骗子地址里 | 有机会，执法机构可以请 Tether 冻结这个地址 |
| 币已经经过混币器、跨链桥换了很多次 | 很低 |
| 币已经换成别的币，流进了去中心化交易所 | 很低 |
| 骗子是你认识的人、有真实身份信息 | 走正常的司法程序 |

所以**速度很重要**。USDT 被冻结的数据可以参考 [黑U 和 USDT 冻结](<./24-什么是黑U？USDT 为什么会被冻结，收到涉案 USDT 怎么办，C2C 和转账怎么避开.md>)那篇里的统计：Tether 每年冻结的金额以亿美元计，大部分都来自执法机构的要求。

## 五、报警，联系交易所

### 1. 报警

带上第三节整理好的证据，到当地派出所报案，或者拨打 110。报案以后拿到**报案回执**，后面联系交易所、联系 Tether，都需要执法机构出面或者提供这份材料。

### 2. 联系交易所

- **你自己的交易所账户被盗**：在 App 内的在线客服提交工单，说明情况，提供证据；
- **币流进了某家交易所**：在那家交易所的官方渠道提交说明，并告诉办案民警币流进了哪家交易所、哪个地址，由执法机构向交易所发出协查。

普通用户自己直接找交易所，一般只能「登记情况」，**真正能冻结资金的，是执法机构的协查**。

## 六、千万小心「追回大师」二次诈骗

币被盗以后，你在社交平台发帖求助，很快就会有人私信你：

- 「我是白帽黑客，可以帮你追回，先付 10% 定金」；
- 「我们是区块链律师事务所，追回成功率 90%」；
- 「我能联系到交易所内部的人，帮你冻结骗子的账户」；
- 「先转一笔 USDT 到这个地址，用来『激活』追回程序」。

**这些全部是骗子**。链上转账一旦完成，没有任何人能通过「技术手段」把币转回来；能冻结资金的，只有交易所、Tether 和执法机构，而这些都是通过正式渠道处理的，不需要你先付钱。

![追回骗局的 4 种话术：白帽黑客收定金、律师事务所保证成功率、交易所内部关系、先转一笔激活](https://invest-nav.com/tutorial-content/new-2026-11-01/crypto-stolen-what-to-do/fig-03.webp)

## 七、以后怎么避免？

1. **助记词只写在纸上**，不截图、不存云端、不发给任何人，任何要你提供助记词的都是骗子；
2. **交易所开启谷歌验证器和防钓鱼码**，邮箱也要开两步验证；
3. **大额长期持有的币放进[冷钱包](<../04-Web3钱包/08-冷钱包教程：Ledger、SafePal、OneKey 怎么选，购买、激活、转入比特币和助记词保管.md>)**，交互用的钱包只放小钱；
4. **定期检查和取消钱包授权**；
5. **「稳赚不赔」「带单老师」「内部渠道」一律不信**，更多套路看[币圈防骗指南](../02-加密货币基础/14-币圈常见骗局有哪些？钓鱼、假客服与貔貅盘防骗指南.md)；
6. **交易所只用官方 App 和官网**，不点陌生链接。

## 写在最后

币被盗、被骗以后，按这个顺序来：**先止损保住剩下的，再存证据、查去向，然后报警、联系交易所**。币流进大交易所、被盗的是 USDT、报案又及时，都还有机会冻结追回。

最后再强调一次：任何主动找你、说能帮你追回的人，都是第二批骗子。别让一次损失，变成两次。
