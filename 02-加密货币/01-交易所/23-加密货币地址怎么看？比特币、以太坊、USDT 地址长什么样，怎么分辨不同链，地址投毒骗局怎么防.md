# 加密货币地址怎么看？比特币、以太坊、USDT 地址长什么样，怎么分辨不同链，地址投毒骗局怎么防

作者：[Nico 投资有道](https://www.youtube.com/@NicoGrowthz) · [投资导航网页版](https://invest-nav.com/tutorials/exchanges/text/crypto-address-guide/) · [返回本分类](./README.md)

提币的时候要填一长串地址，看都看不懂，怎么知道它对不对？为什么有的地址是 0x 开头，有的是 T 开头，还有的是 bc1 开头？同一个地址，在不同的网络上能不能通用？

地址是币圈最基础、也最容易出错的东西。转错网络、漏填 Memo、复制了别人伪造的地址，币一旦转出去，几乎没有撤回的可能。而最近很流行的「地址投毒」骗局，专门利用大家只看地址开头几位和最后几位的习惯，很多老用户都中过招。

今天这篇教程，我会把各条链的地址长什么样、怎么分辨一次性讲清楚，再带你避开转账时最常见的几个坑，告诉大家整个过程中需要注意的事项。

那我们话不多说，尽快开始今天的内容。

## 一、地址到底是什么？

你可以把地址理解成**链上的收款账号**。别人往这个地址转币，币就到了这个地址里；谁掌握这个地址对应的私钥，谁就能把币转走。

和银行账号不一样的是：

- **地址是链上的，不是交易所的**：每条链有自己的一套地址格式，比特币链、以太坊链、波场链的地址互不相同；
- **转出去就撤不回**：链上转账没有「撤销」按钮，转错了基本只能自认倒霉；
- **任何人都能查**：任何人都可以在区块浏览器里，看到一个地址里有多少币、转进转出过哪些交易。

## 二、各条链的地址长什么样？

不同的链，地址的开头和长度都不一样。记住下面这张表，一眼就能看出一个地址大概是哪条链的：

| 链 | 地址开头 | 长度 | 常见用途 |
| --- | --- | --- | --- |
| 比特币 | bc1、1、3 | 26–62 位 | BTC |
| 以太坊及 EVM 链 | 0x | 42 位 | ETH、ERC20 的 USDT，以及 BSC、Arbitrum、Polygon 等链 |
| 波场 TRON | T | 34 位 | TRC20 的 USDT |
| Solana | 没有固定开头 | 32–44 位 | SOL、Solana 链上的 USDT |
| Aptos | 0x | 66 位 | APT、Aptos 链上的 USDT |

![各条链的地址长什么样：比特币 bc1、1、3 开头，以太坊和 EVM 链 0x 开头 42 位，波场 T 开头 34 位，Solana 没有固定开头，Aptos 0x 开头 66 位](https://invest-nav.com/tutorial-content/new-2026-11-01/crypto-address-guide/fig-01.webp)

### 比特币的三种地址

比特币地址有三种开头，都能收 BTC，区别在于转账手续费：

- **bc1 开头**：最新的格式，转出时手续费最低，现在交易所和钱包默认用这种；
- **3 开头**：兼容格式，手续费中等；
- **1 开头**：最老的格式，手续费最高。

这三种地址之间可以互相转账，不会出问题，只是 bc1 更省钱。

### 0x 地址：一个地址，多条链通用

以太坊、BSC（币安智能链）、Arbitrum、Optimism、Polygon、Base 这些链，都属于 **EVM 链**，用的是同一套地址格式，都是 0x 开头的 42 位。

这带来一个很容易误解的地方：**同一个 0x 地址，在这些链上都是有效的，但它们是不同的链，币不互通。**

举个例子：你在 Web3 钱包里有一个 0x 地址。别人往这个地址转了 100 USDT，选的是 BSC 网络，这 100 USDT 就在 BSC 链上；你去以太坊链上看这个地址，余额是 0。这时候：

- 如果这个地址是你自己的 Web3 钱包：切换到 BSC 网络就能看到，币没丢；
- 如果这个地址是交易所的充值地址：而交易所这个币种只支持以太坊网络充值，那这笔 BSC 上的币，交易所就收不到了，只能找客服申请找回。

**所以，地址格式对得上，不代表网络选对了。** 提币的时候，网络一定要和收款方支持的网络完全一致。各个网络怎么选，可以看[提币网络怎么选](<./28-USDT 提币选哪个网络？TRC20、ERC20、BSC 有什么区别，转错链、漏填 Memo 怎么办.md>)。

## 三、交易所充值地址的 3 个常见问题

### 1. 充值地址能不能重复用？

**可以。** 交易所给你的充值地址，一般是固定分配给你的，同一个币种、同一个网络，每次充值都可以用同一个地址。不过要注意，**不同网络的充值地址不一样**：USDT 的 TRC20 地址和 ERC20 地址是两个完全不同的地址。

交易所偶尔会更换充值地址，每次充值前，最好还是从 App 里重新复制一次，不要一直用很久以前存下来的地址。

### 2. Memo、Tag 是什么？

有些币种和网络，交易所所有用户共用同一个充值地址，再用一串数字来区分是谁的钱，这串数字叫 **Memo** 或者 **Tag**（不同交易所叫法不同）。常见的有 XRP、EOS、TON，以及部分交易所的 Aptos、Sui 等网络。

**需要 Memo 的时候，地址和 Memo 必须一起填。** 漏填了，币会进到交易所的公共地址里，交易所不知道是谁的，只能联系客服、提供交易记录申请找回，一般要等很久，有的还要收手续费。

### 3. 能不能直接从一家交易所提到另一家？

可以，这是最常见的用法：在收款的交易所复制充值地址（有 Memo 就一起复制），回到转出的交易所，选**同一个网络**提币。第一次往一个新地址转账，**先转一笔小额测试**，到账了再转大额。

提币一直没到账怎么排查，可以看[提币没到账怎么办](<./16-交易所提币多久到账？USDT 提币一直没到、显示审核中、链上成功但没到账怎么办.md>)。

## 四、地址投毒：最近很多人中招的骗局

### 骗局是怎么做的？

地址投毒的原理很简单，就是利用大家**只看地址开头和结尾几位**的习惯：

1. 骗子盯上你常用的收款地址，比如 **TQ5x…8Kp2**；
2. 用程序生成一个**开头和结尾都一样**的假地址，比如 **TQ5x…8Kp2**，中间完全不同；
3. 用这个假地址给你转一笔**极小的金额**，甚至 0 USDT，这笔记录就出现在你的转账历史里；
4. 下次你要转账的时候，从转账记录里复制「上次那个地址」，一不小心复制成了骗子的假地址，币就转给了骗子。

![地址投毒怎么骗：骗子生成开头结尾都和你常用地址一样的假地址，转给你一笔 0 USDT，等你从转账记录里复制错地址](https://invest-nav.com/tutorial-content/new-2026-11-01/crypto-address-guide/fig-03.webp)

这个骗局不需要你点任何链接、不需要你授权任何东西，**只要你从转账记录里复制地址，就有可能中招**，金额大的时候损失非常惨重。

### 怎么防？

1. **永远不要从转账记录里复制地址**：每次都从收款方的 App 里重新复制充值地址；
2. **用地址簿或提币白名单**：常用的地址，第一次核对无误后保存到交易所的地址簿，并打开提币白名单，以后只从地址簿里选；
3. **核对完整地址，至少再看中间几位**：开头结尾一样不代表是同一个地址，粘贴后对一下中间的字符；
4. **看到莫名其妙的小额转入或 0 转入，要提高警惕**：这往往说明你的地址已经被骗子盯上了；
5. **大额转账先转小额测试**：小额到账、确认地址无误后，再转剩下的。

## 五、转账前的 5 项检查清单

每次提币之前，按这个顺序检查一遍：

| 检查项 | 怎么做 |
| --- | --- |
| ① 地址来源 | 从收款方 App 里刚复制的，不是从聊天记录、转账记录里复制的 |
| ② 地址格式 | 开头和长度符合这条链的格式 |
| ③ 网络 | 和收款方支持的网络完全一致 |
| ④ Memo | 收款方要求填的，一个数字都不能错 |
| ⑤ 金额 | 第一次往新地址转，先转小额 |

## 写在最后

地址看起来是一串乱码，其实很有规律：比特币看 bc1，以太坊系看 0x，波场看 T。看懂了地址的格式，再配合「网络选一致、Memo 不漏填、先转小额」这几条，绝大多数转账事故都能避免。

至于地址投毒，记住一句话就够了：**地址永远从收款方那里重新复制，不要从转账记录里复制。** 这一个习惯，就能挡住这类骗局。
