# 合约跟单靠谱吗？怎么挑带单员、跟单金额和止损怎么设，欧易跟单从原理到实操一次讲清楚

跟单交易真的能「躺着跟高手赚钱」吗？排行榜上收益率几千倍的带单员能不能跟？跟单亏了钱，带单员要不要负责？

跟单是很多新手进合约的第一站：自己不会做，那就跟着厉害的人做。这个思路没错，但跟单的坑比自己下单还多，最常见的就是被排行榜上的高收益吸引，跟进去以后正好赶上带单员爆仓。

今天这篇教程，我会把跟单交易的原理、分润规则、挑带单员要看哪几个数字一次性讲清楚，再用欧易 App 演示跟单的完整流程，带你避开跟单最常见的几个坑。

那我们话不多说，尽快开始今天的内容。

## 一、跟单交易是怎么回事？

跟单就是：**带单员下单，系统自动帮你按比例下一样的单。**

- 带单员开多比特币，你的账户也自动开多；
- 带单员平仓，你也自动平仓；
- 带单员赚了你跟着赚，带单员亏了你跟着亏。

带单员也不是白帮你，你赚了钱要分一部分给他，这叫**分润**。

欧易的跟单分为合约跟单和现货跟单，大部分人说的跟单是合约跟单，这也是本篇主要讲的。跟单用的是合约，所以合约的风险一样都不少，还没了解过杠杆和强平的，建议先看站内的[合约交易入门](./06-币圈合约交易入门：杠杆、保证金、强平价、资金费率一次讲清楚，新手先看这篇再决定要不要玩.md)。

## 二、分润怎么收？

按欧易帮助中心的规则：

- **分润比例**：由带单员自己设定，最高 30%，详情页上能看到；
- **结算时间**：每周结算一次，每周一 00:00（北京时间）计算上一周的收益；
- **按净利润算**：一周里跟单的盈亏会相互抵消，扣完手续费以后的**净利润**才分润。亏损的那一周不用分；
- **先预扣、后多退**：赚钱的时候平台先预扣一部分，结算时多扣的退回给你；
- **有仓位没平完的，延后结算**：要等相关仓位都平掉以后再算。

举个例子：一周里你跟单 6 笔，盈亏分别是 +200、-50、+300、-500、+500、+100，净利润 550 USDT。带单员分润比例 10%，你要分给他 55 USDT，自己拿到 495 USDT。

### 分润规则背后，你要想明白的一件事

带单员**赚了钱分润，亏了钱不用赔**。这意味着从带单员的角度看，冒大风险是「划算」的：赌对了拿 30% 的分润，赌错了亏的是跟单人的钱，最多就是换个账号重新开始。

不是所有带单员都会这么想，但这个结构决定了：**你必须自己替自己控制风险**，不能指望带单员替你控制。后面讲的投资额上限和跟单止损，就是为了这个。

## 三、挑带单员：别只看收益率

排行榜默认按收益率排序，但**收益率是最容易误导人的数字**。一个带单员用 100 USDT 一个月赚到 1,000 USDT，收益率 900%，看起来很厉害，可他可能只是满仓高杠杆赌对了一两次，下一次赌错就归零。

挑带单员要综合看这 6 个数字：

| 看什么 | 为什么重要 | 参考标准 |
| --- | --- | --- |
| **最大回撤** | 历史上从最高点最多亏过多少，代表你跟进去可能经历的最大亏损 | 越小越好，超过 50% 的慎跟 |
| **带单天数** | 时间越长，越能说明不是运气 | 至少 3 个月以上，最好经历过一次大跌 |
| **收益曲线** | 是稳步向上，还是靠一两次暴涨撑起来的 | 看 90 天曲线，平稳向上的优先 |
| **收益额和带单规模** | 小资金高收益率容易，大资金还能稳定赚钱才难 | 收益额和收益率一起看 |
| **跟单人数和留存** | 很多人长期跟着，说明大家认可 | 结合下面的「坑」一起看 |
| **分润比例** | 直接影响你最后到手多少 | 同样水平的带单员，选比例低的 |

此外还有两个细节可以看：

- **历史带单记录**：看他平时用多少倍杠杆、一笔单子拿多久、有没有设止损。经常 50 倍以上、从不止损的，跳过。
- **当前持仓**：如果公开的话，看看他现在是不是重仓扛着一笔大亏损。

### 拿一个真实的带单员看一看

我截图这天，欧易合约跟单列表里排在前面的一位带单员 IS.K，近 90 日收益率 **+638.70%**，收益额 16.9 万美元，带单 188 天，跟单人数 11/301（现在 11 人跟，上限 301 人），收益曲线一路向上。只看列表，很容易心动。

但点进「历史带单」往下翻，就能看到他的真实风格：全仓 **30 倍**做 SNDK 永续，一笔单子 50 分钟亏了 **88.41%**，亏掉 1,784.94 USDT；前后几笔原油（CL）永续用的是全仓 20 倍，其中一笔赚了 99%。他自己在简介里也写着「暂时的回撤是正常的，复制前请了解风险」。

这就是典型的高收益、高杠杆风格：赌对了收益率很好看，赌错一次就是大半个本金。**收益率 600% 和单笔亏 88%，是同一个人的两面。** 这也是为什么一定要点进历史带单看一看，而不是只看列表上的收益率。

### 为什么最大回撤比收益率重要？

亏损和回本不是对称的。亏掉 50%，要涨 100% 才能回本：

| 亏损 | 回本需要赚 |
| --- | --- |
| 10% | 11% |
| 30% | 43% |
| 50% | 100% |
| 70% | 233% |

一个最大回撤 70% 的带单员，就算他后来又赚回来了，你跟进去的时机不对，就可能正好扛住那 70% 的亏损，而且大部分人在亏到 40%–50% 的时候就扛不住割肉了，根本等不到他赚回来的那一天。

![亏得越多回本越难：亏 10%、30%、50%、70% 分别要赚 11%、43%、100%、233% 才能回本](https://invest-nav.com/tutorial-content/new-2026-11-01/crypto-copy-trading-guide/fig-01.webp)

### 小心「高胜率」带单员

有一类带单员的数据特别好看：胜率 90% 以上，收益曲线一路平滑向上。点开历史记录，会发现他的特点是：

- 每笔赚得很少，比如 2%–3% 就平仓；
- 亏的单子从来不止损，一直扛着，直到价格回来；
- 平均持仓时间里，亏损单比盈利单长得多。

这种打法在震荡行情里可以连续赚几个月，但只要遇到一次单边行情，扛着的那一单就会爆仓，**一次把几个月的利润全部亏回去，还要倒贴本金**。

判断方法很简单：在历史记录里找到他的**最大单笔亏损**，和平均单笔盈利比一下。最大单笔亏损是平均盈利的 10 倍以上、而且亏损单都拿得特别久的，基本就是这种打法。

![两种收益曲线：稳步向上的带单员和胜率很高但一次扛单爆仓的带单员](https://invest-nav.com/tutorial-content/new-2026-11-01/crypto-copy-trading-guide/fig-02.webp)

### 用三个带单员练一下手

假设排行榜上有这三个人：

| | A | B | C |
| --- | --- | --- | --- |
| 90 天收益率 | 860% | 65% | 38% |
| 最大回撤 | 72% | 18% | 9% |
| 带单天数 | 25 天 | 410 天 | 380 天 |
| 胜率 | 58% | 61% | 93% |
| 常用杠杆 | 50–100 倍 | 5–10 倍 | 10–20 倍 |
| 最大单笔亏损 / 平均盈利 | 4 倍 | 3 倍 | 25 倍 |

- **A**：收益率最高，但带单才 25 天，回撤 72%、杠杆 100 倍，大概率是赌对了几次，**不跟**；
- **C**：胜率 93%、回撤只有 9%，看起来最稳，但最大单笔亏损是平均盈利的 25 倍，很可能就是上面说的扛单型，**不跟**；
- **B**：收益率不是最高，但带单一年多、回撤可控、杠杆不高、盈亏比正常，**这才是值得考虑的人**。

## 四、跟单的实际收益，为什么总比带单员低？

很多人跟了一段时间会发现：带单员页面上显示赚了 20%，自己的跟单账户只赚了 12%。这很正常，差距主要来自四个地方：

1. **分润**：赚的钱要分 10%–30% 出去；
2. **成交价差**：带单员先成交，跟单的订单随后成交，行情快的时候价格会差一点；跟的人越多，这个差距越大；
3. **手续费**：每一笔跟单都有开仓、平仓手续费，带单员交易越频繁，这部分越多；
4. **跟进去的时间点**：带单员 90 天赚 65%，不代表你这 30 天也能赚，他的收益可能集中在你跟进去之前的某一段。

所以评估一个带单员值不值得跟，可以先把他的收益率打个**六到七折**，再看还有没有吸引力。

![跟单收益为什么比带单员低：分润、成交价差、手续费、跟进时机依次扣减](https://invest-nav.com/tutorial-content/new-2026-11-01/crypto-copy-trading-guide/fig-03.webp)

## 五、跟单最常见的 5 个坑

1. **排行榜追高**：收益率榜前几名，往往是最近一段时间赌得最凶的人。等你看到他、跟进去，常常正好是他运气最差的时候。
2. **带单员也会爆仓**：带单员不保证收益，他爆仓了，你跟单的那部分一样会被强平。跟单亏损，带单员不负任何责任。
3. **跟单人数太多反而有问题**：跟的人非常多时，大家的单子会一起成交，你的实际成交价可能比带单员差一点，赚得比他少。
4. **只跟一个人、跟太多钱**：把一大笔钱押在一个带单员身上，他一次失误你就伤筋动骨。
5. **跟进去就不管了**：带单员的风格会变。前三个月稳稳当当，后面亏了想翻本，突然开始加杠杆、做小币，你不看就不知道。

## 六、跟单金额和止损怎么设？

现在点「立即跟单」，欧易默认弹出的是**智能跟单**，只有三项要填：

### 1. 智能跟单投资额

这是你准备投在这个带单员身上的**总金额**，也就是最大跟单金额。智能跟单会按照带单员每一笔买入成本占他资金的比例，给你等比例下单：他用一成资金开一单，你也用你投资额的一成去跟。

截图里我填的 5,000 USDT 只是演示，没有真的跟。第一次建议只放 10–20 USDT，跟一两周，看看实际收益和带单员页面上显示的差多少。

### 2. 立即市价复制仓位

勾上的话，带单员**现在手里已经开着的仓位**，会马上按市价给你复制一份。不勾的话，只跟他之后新开的单子。

带单员当前的仓位可能已经浮盈很多、也可能正扛着亏损，你按现价跟进去，成本和他完全不一样。**新手建议不勾**，只跟之后的新单。

### 3. 跟单止损

展开「高级设置」，有一个「跟单止损」，填的是 USDT 金额。这是最重要的一个设置：比如投资额 200 USDT，止损填 60 USDT，亏到 60 USDT 就自动停止跟单。这样就算带单员连续犯错，你最多也只亏 60 USDT，而不是全部。

### 4. 想用固定金额跟，点「自定义模式」

止损下面有一个「自定义模式」入口，可以改成更细的设置：

- **固定金额**：带单员每开一单，你都用固定的金额跟，比如每单 20 USDT。好控制，适合想精确控制每一单大小的人；
- **固定比例**：按带单员仓位的一定比例跟，他加大仓位你也跟着加；
- **单笔止盈止损**：给每一笔跟单设止盈止损，比如单笔亏损 20% 自动平仓。带单员某一单不止损、一直扛着的时候，你这边会先离场。

### 5. 一个参考的设置方案

假设你准备拿 **500 USDT** 试跟单：

- 分给 **2–3 个风格不同的带单员**，每人投资额 150–200 USDT；
- 每个人的**跟单止损设成投资额的 30%**，比如投 200 就填 60；
- 不勾「立即市价复制仓位」；
- 想再细一点，就用自定义模式加上单笔止损 20%–30%。

这样最坏的情况，是三个人同时触发跟单止损，总共亏 150 USDT 左右，也就是 30%。而且三个人同时出问题的概率，远比一个人出问题小。

## 七、欧易跟单实操

### 1. 进入跟单

打开欧易 App → 底部「交易」→ 顶部切到「策略&跟单」，往下找到「跟单交易」，点进去就是带单员列表。列表上方可以切换合约、现货、TradFi、策略、信号几类带单，新手先看合约。

### 2. 排序和筛选

列表默认是「综合排序」，点开还可以按胜率、收益率、收益额、带单规模、当前跟单人数、跟单用户收益来排。

我比较推荐按**跟单用户收益**排一次：它看的是跟着这个人的用户实际赚了多少，比带单员自己的收益率更接近你跟进去以后的真实结果。

### 3. 看带单员详情

点进一个带单员，「带单表现」里能看到收益率曲线，可以切 7 天、30 天、90 天、1 年，下面还有每周收益额的柱状图。再往右是「当前带单」「历史带单」「跟单用户」三个标签，历史带单一定要翻一翻，看他用多少倍杠杆、一笔拿多久、亏损的单子亏了多少。

### 4. 设置跟单

挑好以后点「立即跟单」，按第六节填投资额、决定要不要勾「立即市价复制仓位」、设好跟单止损，再点「立即跟单」确认。

![图 6：欧易智能跟单的投资额和跟单止损设置](https://invest-nav.com/tutorial-content/new-2026-11-01/crypto-copy-trading-guide/steps-02.webp)

### 5. 查看收益和取消跟单

跟上以后，在「策略&跟单」页顶部的「我的跟单」里，能看到你正在跟的带单员、当前持仓和累计收益。

不想跟了，在「我的跟单」里取消跟单。取消时一般会问你，是立刻平掉现在跟着的仓位，还是保留仓位以后自己平。不确定的话选立刻平仓，避免仓位没人管。

## 八、跟进去以后，每周看一次

跟单不是一劳永逸。建议每周花几分钟，在「我的跟单」和带单员详情页看一下，出现下面任何一个信号，就考虑停止跟单：

1. **回撤超过了他的历史最大回撤**：说明他现在的状态比过去任何时候都差；
2. **杠杆突然变大**：平时用 5 倍，最近开始用 20 倍、50 倍；
3. **交易的币种变了**：平时只做比特币、以太坊，最近开始频繁做小币；
4. **交易频率突然变高**：平时一周几单，最近一天几十单，很可能是在急着翻本；
5. **跟单人数快速流失**：很多人在同一段时间取消跟单，往往说明大家看到了你没注意的问题。

停止跟单不需要等到亏损触发止损。**看到风格变了就走**，比等着止损触发要少亏很多。

## 写在最后

跟单不是把赚钱外包给别人，而是**你自己挑一个人、承担他的全部风险**。挑带单员看回撤和时间，而不是看收益率排名；设好投资额上限和跟单止损；先小额跟一段时间再决定要不要加。

做到这几点，跟单才是一个帮你学习、帮你省力的工具，而不是一张开往爆仓的车票。
