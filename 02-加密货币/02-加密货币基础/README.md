# 加密货币基础

这是「加密货币从 0 到 1」系列教程，共 12 篇，面向完全没有接触过加密货币的读者。

系列分四个部分。前四篇讲基础概念，把加密货币、比特币、以太坊和稳定币分别说清楚。第五篇是实操，讲交易所的注册认证与入金买入。第六到第九篇回到行业层面，梳理 Web3 各赛道的现状、项目投研方法，以及 Perp DEX 和代币化股票这两条新赛道。第十到第十二篇落到个人决策，讲赚钱路径、投资策略和防诈要点。

按顺序阅读效果最好。如果时间有限，建议至少先读完前六篇，把基础认知和交易所操作建立起来，再进入后面的部分。

> 加密行业变化较快，涉及市场数据的内容都会标注时间点。数据只说明当时的情况，请以最新数据为准。
