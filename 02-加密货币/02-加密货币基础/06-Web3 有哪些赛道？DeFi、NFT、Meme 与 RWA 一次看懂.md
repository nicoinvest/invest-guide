# Web3 有哪些赛道？DeFi、NFT、Meme 与 RWA 一次看懂

前面几篇讲的是单个资产。这一篇我们退一步，看看 Web3 这个行业整体上有哪些方向哪些赛道。

最近几年随着 Web3 的发展，涌现出了非常多的热门赛道，如果要挨个讲解一遍的话，可能三天三夜都说不完。所以我大概列一下几个主流赛道，并挑选其中最值得关注的赛道，详细和大家分享一下我的见解。

需要提醒一句，这个行业的赛道更替非常快，我下面提到的赛道只是我自己之前关注过了解过的赛道，并不代表它们当下的热度。

关于最近一段时间最火热的赛道，接下来会有四篇教程，给大家详细介绍。

![Web3 主要赛道地图](https://pub-f5a7bf3ec58b4dbea87a9eb7feddfabe.r2.dev/tutorial-content/crypto-basics-refresh-2026-09-23/06-body-01.webp)

## 1. Layer 2

第一个赛道是 Layer 2，在介绍以太坊部分的时候，其实我们已经详细讲解过一遍了。

我再列举一下 Layer 2 赛道中很火的 Web3 项目，龙一和龙二分别是 Arbitrum 和 Optimism。

可能你并不了解这两个项目，但只要你接触过以太坊链上转账，一定有用到过它们，因为通过二层网络来转账的话，Gas 费非常低，只需要几美分，基本上可以说是零成本。这也是 Layer 2 的最大优势。

**目前的位置：大幅收缩。** Layer 2 的总锁仓量从高峰期的 480 多亿美元，跌到 2026 年 7 月的约 50 亿美元。原因有两个，一是二层网络数量太多，流动性被切得极碎，以太坊上曾经有七十多条 rollup 争夺同一批用户；二是二层做大之后反而抽走了主网的交易量和手续费收入。2026 年 2 月，原本基于 OP Stack 构建的 Base 宣布脱离该技术栈，OP 代币当天跌超 20%。

## 2. DeFi 去中心化金融

第二个赛道是 DeFi，它的全称是 Decentralized Finance，相当于把传统金融的那一套东西，在去中心化的区块链上复刻了一遍，涵盖了交易、借贷、衍生品服务。它算是 Web3 的第一个现象级大规模应用。

这个赛道在上一轮牛市，也就是 2020 年夏天的时候，经历了一波大爆发，取得了突破性的进展，市值和用户都大幅增长，又被称之为 DeFi Summer。

其中最出名的项目就是 Uniswap 去中心化交易所和 Aave 去中心化借贷协议，直到现在也仍然是 DeFi 的龙头项目。

**目前的位置：回暖。** DeFi 的链上锁仓量回到 1,300 亿到 1,400 亿美元区间，是这一轮里少数有真实收入和真实用户的赛道。

## 3. NFT

第三个赛道是 NFT，中文名是非同质化代币，它就是数字收藏品，每一件都是独一无二的，比如一张数字画或游戏里的武器，记录在区块链上，证明你拥有。

其中非常火的一个艺术收藏品是 CryptoPunk 像素人，即使你没有听过，但你大概率见过，前两年的时候非常火。

但这个赛道投机性比较高，非常容易出现价格泡沫。

**目前的位置：基本退潮。** 风险投资在这个方向上的投入，从 27 笔、1.15 亿美元，缩水到 2 笔、1,470 万美元。

## 4. DID 与 DePIN

第四个赛道是 DID，全称是 Decentralized Identifier，它是基于区块链的数字身份系统，用户可以控制自己的身份数据，保护隐私。

在 Web3 的世界中，并没有人的概念，而是一个个数字钱包地址，而且创建钱包地址的成本非常低，用户随时可以创建，也可以随时放弃。而 DID 的目的就是，在去中心化的世界里，构建起身份认证系统，用户隐私可以得到保护，进一步参与到 Web3 的生态中。

还有一个是 DePIN，英文全称是 Decentralized Physical Infrastructure Network，去中心化物理基础设施。它有点类似于共享经济，比如说我们可以把自己手头多余的算力提供出来，然后赚取项目方的代币，相当于我们的租赁收益。

**目前的位置：边缘化。** 这两个方向都有真实的技术价值，但多数项目缺乏足够多的真实用户，运营上比较依赖代币激励。

## 5. GameFi 与 SocialFi

第五个赛道是 GameFi，这个很好理解，就是将游戏引入区块链，我们通过玩游戏，就可以赚取到 GameFi 项目对应的原生代币，相当于一边打游戏，一边投资赚钱，愿景还是非常不错的。

第六个赛道是 SocialFi，它是将社交媒体引入到区块链中，我们在社交媒体发帖留言互动的时候，就可以赚到对应的代币。听起来和 GameFi 是不是非常类似？都是在 Web2 相关产品的后缀上加一个 Finance，再配合项目方发币，就摇身变成了 Web3 项目。

**目前的位置：GameFi 基本停摆，SocialFi 边缘化。** 数据显示约 93% 的 Web3 游戏项目已经停止运营，代币价格平均回撤约 95%，曾经的龙头 Axie Infinity 月活从 280 万掉到不足一万。这两个赛道暴露的是同一个问题，激励一旦停止，用户就走，因为留下的唯一理由就是赚钱。

## 6. InfoFi

第七个赛道是 InfoFi，举一反三，它的全称很好猜，就是 Information Finance。

在当下信息时代，信息是最不值钱的东西，而用户的注意力是最值钱的，比如说我们每天都在刷抖音，那么抖音平台就可以用我们的注意力，去换取广告商的广告费，转化为真正的商业价值。

而 InfoFi 的核心意义就是将注意力代币化，将原本抽象的注意力，转变为可以量化的积分模型。根据积分排名，把代币分发给优质的信息贡献者，而这些信息贡献者的任务就是挖掘分享其它优质的 Web3 项目。

当时两个很火的 InfoFi 项目是 Kaito 和 Cookie。

**目前的位置：已经崩塌。** 2026 年 1 月，X 修改 API 政策，封禁了付费发帖类应用。这类项目依赖平台激励，政策一出就失去了根基，板块市值跌到约 3.5 亿美元，几个头部项目相继关停了核心功能。

## 7. Agent

第八个赛道是 Agent，其实就是将 Web3 与传统的 AI Agent 相结合，这个 Agent 能够在区块链上自主操作，完成复杂的任务，无需人工干预。

**目前的位置：先暴涨后大幅回撤。** 板块市值从 2025 年初的约 90 亿美元，一度冲到 2026 年 5 月的 2,200 亿到 2,700 亿美元，随后在 2026 年一季度代币普遍回撤 80% 到 90%。活下来的是有真实使用场景的部分，主要是链上支付标准和身份协议这类基础设施。

## 8. Meme 币

最后一个赛道是 Meme 币，这个赛道很有意思，它没有任何实际的用途和价值，只是单纯地由社区文化推动，比如说我们熟知的狗狗币，它的原型其实就是 Doge 表情包，还有就是 2023 年爆火的 Pepe，也是单纯地由社区推动。

Meme 币赛道确实诞生了非常多的暴富神话，但是它的投机性非常强，价格波动非常剧烈，尤其是对于那种市值不到 1 亿的 Meme 币，归 0 的可能性非常高。所以不建议新手小白去碰这种币。

**目前的位置：一直很活跃，但分化剧烈，不同链的 meme 币存在天壤之别。** 热度越来越依赖个别平台和事件驱动。以 2025 年初发行的川普币为例，发行当天价格一度冲到 70 多美元，目前价格较最高点已经回落超过 97%，绝大多数参与者是亏损的。

## 9. RWA 现实世界资产

另外一个重要的赛道就是 RWA，它的全称是 Real World Asset，意思就是将传统世界的资产，通过 Token 代币化的形式，在区块链上发行，就比如最近很火的美股代币化赛道，就是 RWA 的一部分。

还有就是稳定币，它其实是世界上第一个代币化资产，相当于将法币，以 token 的形式映射到了区块链上。

RWA 一旦落地，全世界任何一个人都可以轻松接触和拥有美元资产。尤其是对于大陆用户、想要无门槛投资美股的朋友们来说，RWA 赛道是最佳选择。

RWA 的最大意义是彻底打破了时空的限制，实现了全球化准入与资产民主化，所以说它可能是史上最伟大的金融平权运动。

而目前 RWA 赛道还是处于非常早期的阶段，各大机构、公司刚开始布局这一赛道。

根据波士顿咨询集团的报告预计，代币化资产的市场在 2030 年将达到 16 万亿美元，占 2030 年代末全球 GDP 的 10%。这是机构给出的预期，分歧很大，仅作参考。

**目前的位置：稳步扩张。** 链上代币化资产的发行规模已经超过 270 亿美元，覆盖的项目超过 3,200 个。这部分我会在后面的教程里单独展开。
