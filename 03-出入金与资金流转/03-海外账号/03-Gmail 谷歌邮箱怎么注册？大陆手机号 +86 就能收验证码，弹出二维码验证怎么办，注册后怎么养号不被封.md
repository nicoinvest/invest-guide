# Gmail 谷歌邮箱怎么注册？大陆手机号 +86 就能收验证码，弹出二维码验证怎么办，注册后怎么养号不被封

作者：[Nico 投资有道](https://www.youtube.com/@NicoGrowthz) · [投资导航网页版](https://invest-nav.com/tutorials/overseas-accounts/text/gmail-register-guide/) · [返回本分类](./README.md)

想注册一个 Gmail 谷歌邮箱，结果一直弹出二维码验证，扫了也过不去？是不是一定要海外手机号？好不容易注册好了，过几天又被封了，怎么办？

Gmail 是我们用海外服务绕不开的一个账号：开海外银行、注册交易所、订阅 AI 工具、登录 YouTube，很多地方都要用到它。但最近几个月，Google 又升级了新号注册的验证，很多朋友在注册的时候，大概率会弹出二维码验证，卡在这一步。

今天这篇教程，我会把 Gmail 的注册步骤、二维码验证到底是怎么回事，以及注册好之后怎么养号一次性讲清楚，带你避开最常见的几个坑。

那我们话不多说，尽快开始今天的内容。

## 一、先说结论：问题出在网络，不在手机号

很多人以为注册 Gmail 一定要海外手机号，其实不是。

**这一步根本用不到海外手机号，国内 +86 的手机号就可以成功注册。**

弹出二维码验证的本质原因，在你的网络 IP 上。如果你用的网络 IP 不干净，比如很多人共用的节点、经常被拿来批量注册的节点，Google 就会判定风险比较高，弹出二维码验证。

反过来，只要你的网络环境干净稳定，注册时只需要接收一条手机验证码，不会弹出二维码验证。

## 二、注册前准备

| 准备什么 | 说明 |
| --- | --- |
| 手机号 | 国内 +86 手机号就可以，用来接收验证码 |
| 海外网络 | 要稳定、干净的海外节点，我用的是美国节点 |
| Gmail App | 在手机上下载 Gmail 官方 App，用 App 注册 |

关于网络，我自己是买了一台美国洛杉矶的 VPS 服务器，搭了一个只有我自己用的节点，然后在手机上用 Shadowrocket（小火箭）连接这个节点。这样用的 IP 只有我一个人在用，非常干净。

如果你用的是机场节点，可以多试几个不同地区的节点，找一个注册时不弹二维码的。注册过程中不要切换节点。

## 三、Gmail 注册步骤

连好网络之后，在手机上打开 Gmail App，按下面的截图一步步走。

### 1. 添加账号、填姓名和生日

- **图 1**：在 Gmail App 里点右上角头像，选「添加其他账号」，在「设置电子邮件」里选「Google」。
- **图 2**：进入 Google 登录页，点左下角的「创建账号」。
- **图 3**：选择「个人用途」。
- **图 4**：填姓名，姓氏可以不填，名字可以写中文，也可以写拼音。
- **图 5**：填出生日期和性别，出生日期建议按真实的填，年龄要满 18 岁。

- **图 7**：如果提示「已有人使用了该用户名」，可以换一个，或者直接点下面推荐的可选用户名。

注册好之后，建议马上加一个辅助邮箱，比如你常用的 QQ 邮箱或者另一个 Gmail。以后忘了密码、换了手机，都能通过辅助邮箱找回账号。

先验证身份：

- **图 15**：在 Gmail App 里点右上角头像，点「管理您的 Google 账号」。
- **图 16**：页面顶部会有一条黄色提示「不用再担心无法登录 Google 账号」，点「添加辅助邮箱」。
- **图 17**：Google 会先验证身份，勾选「进行人机身份验证」，点「下一步」。
- **图 18**：再输入一次刚才设置的密码。

## 四、注册好之后，怎么养号不被封

新注册的 Gmail，最怕的就是用了几天就被封。养号的核心只有一句话：**像一个正常人一样使用邮箱。**

具体来说，有这几个习惯：

1. **绑定手机号和辅助邮箱**：上面注册时已经绑好了，账号出问题的时候，能通过手机号或辅助邮箱找回。
2. **避免频繁切换设备和网络环境**：今天用美国节点、明天用日本节点，或者一会儿手机一会儿电脑，都容易被判定为异常。
3. **一个设备不要登录太多邮箱账号**：我自己一共就 3 个号，而且不会频繁切换。
4. **避免短时间内大量发送或接收邮件**：新号前几天正常收发几封就好。
5. **用这个账号登录 YouTube，多看看视频**：让账号有一些正常的使用记录。
6. **订阅一些网站的邮件推送**：让邮箱里有正常的往来邮件。

注册好之后，建议马上开启两步验证，账号会更安全。两步验证可以用谷歌验证器，设置方法看[谷歌验证器怎么用](./02-谷歌验证器怎么用：交易所、钱包两步验证设置，换手机怎么迁移.md)。

## 五、常见问题

**注册时一直弹出二维码验证，扫码之后也过不去，怎么办？**

二维码验证的原因在网络 IP，扫码也很难通过。换一个更干净的节点，最好是只有自己在用的节点，再用手机上的 Gmail App 重新注册。

**一定要用美国节点吗？**

不一定，关键是节点要干净、稳定。我用的是美国节点，注册和之后使用都保持同一个地区，不要来回换。

**+86 手机号收不到验证码怎么办？**

先确认手机号没有开启拦截境外短信，等一两分钟再重新发送。同一个手机号短时间内注册太多账号，也可能收不到验证码。

**注册好的 Gmail 能用来做什么？**

开海外银行、注册加密货币交易所、订阅海外服务、登录 YouTube 和 Google Play，基本上都会用到。我在[大陆用户香港必做的 4 件事](<../../01-美股投资/01-香港境外银行/11-大陆用户香港必做的 4 件事：港卡｜香港手机卡｜美股券商｜Gmail 邮箱.md>)里也把 Gmail 列为必备的账号之一。
