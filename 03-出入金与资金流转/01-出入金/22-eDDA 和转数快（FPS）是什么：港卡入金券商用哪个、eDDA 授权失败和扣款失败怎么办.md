# eDDA 和转数快（FPS）是什么：港卡入金券商用哪个、eDDA 授权失败和扣款失败怎么办

作者：[Nico 投资有道](https://www.youtube.com/@NicoGrowthz) · [投资导航网页版](https://invest-nav.com/tutorials/fund-transfer/text/edda-fps-broker-deposit/) · [返回本分类](./README.md)

开好港卡、准备入金券商的时候，大家最常碰到两个词：eDDA 和转数快（FPS）。

这两个都是香港银行的即时转账服务，很多券商入金页面上两个选项并排放着。它们到底有什么区别、该选哪个、eDDA 授权为什么总是失败，这篇一次讲清楚。

## 结论速览（2026 年 10 月核对）

- **转数快（FPS）**：香港的即时转账系统，相当于香港版的「手机号转账」。你自己在银行 App 里输入手机号、邮箱或 FPS ID，把钱转出去，几秒到账，个人转账一般不收费。
- **eDDA**：转数快上的一个功能，全称是电子直接付款授权。你在券商 App 里授权一次，之后每次入金，券商直接从你的港卡里把钱扣走，不用再打开银行 App。
- **区别一句话**：转数快是你「推」钱过去，eDDA 是券商来「拉」钱。
- **入金券商选哪个**：券商支持 eDDA 就优先用 eDDA，比如复星。授权一次，以后在券商 App 里输金额就能入金，交易日一般几分钟到账，复星不收入金手续费。
- **授权失败最常见的原因**：券商那边的姓名拼音、证件类型、证件号码、预留手机号，有一项和港卡开户时登记的不一样。最典型的是盈透：用身份证开的盈透、用港澳通行证开的港卡，第一次授权大概率被拒，补传港澳通行证就能解决。
- **扣款失败要小心**：港卡余额不够时扣款失败，银行会按「结余不足被退回」收费，中银香港每笔 165 港币，其他银行也差不多。入金前先确认钱已经在港卡里。

## 一、转数快和 eDDA 有什么区别

![转数快是你自己在港卡 App 里转出去，几秒到账；eDDA 是授权一次之后由券商从港卡扣款，入金只在券商 App 输金额，港卡余额不够会扣款失败被收费](https://invest-nav.com/tutorial-content/new-2026-10-25/edda-fps-broker-deposit/fig-01.webp)

| | 转数快（FPS） | eDDA |
| --- | --- | --- |
| 谁发起 | 你自己在银行 App 里转出 | 券商按你的授权，从你的港卡扣款 |
| 要不要打开银行 App | 每次都要 | 只有第一次授权要确认，之后不用 |
| 怎么填收款方 | 手机号、邮箱、FPS ID 或银行账号 | 第一次授权时绑定你的港卡账户 |
| 到账速度 | 几秒 | 交易日一般几分钟 |
| 金额上限 | 跟着银行的转数快每日限额走 | 每条授权单独设上限，同时受银行限额影响 |
| 常见用途 | 港卡之间互转、给熊猫速汇这类平台付款、给券商的收款账户转账 | 入金券商、定期扣款 |
| 能不能取消 | 转出就到账了 | 在银行 App 里随时可以取消授权，取消后券商就扣不了款 |

两者用的是同一套香港转账系统，所以 eDDA 也是即时的。区别只在于钱是谁发起转走的。

## 三、以复星为例，eDDA 怎么开通

1. 打开复星 App，点下方「账户」，再点「存入资金」，选币种。
2. 入金方式选 eDDA，点「授权开通」，再点「香港银行账户」。
3. 填港卡信息。以汇丰为例：银行代码 004；姓名填你的姓名拼音，姓在前、名在后；账户类型选综合账户；账户号码到汇丰 App 里查。
4. 上传银行账户凭证，直接用汇丰 App 里显示姓名的个人档案页截图就行。
5. 银行开户证件类型选港澳通行证，填证件号码和开港卡时预留的手机号，点「授权开通」。
6. 一般几分钟授权就通过了。之后再进「存入资金」，能看到「eDDA 已授权」，点「立即入金」输金额就行。

这里要注意第 3、5 步：姓名、证件类型、证件号、手机号必须和你开港卡时登记的一模一样。用港澳通行证开的港卡，这里就选港澳通行证，不要选身份证。

还有一个例外：我用中银香港 App 开的户，在券商这里选港澳通行证授权失败，换成身份证重新提交就通过了。哪个证件被拒，就换另一个再试，结果几分钟就出来。

## 四、盈透的 eDDA 怎么开通

盈透的 App 不太好用，建议在电脑上登录盈透网页端操作。

1. 登录后点「转账与支付」→「转账资金」，在「存入资金」下面点「选择」，再点「使用新的存款方式」。
2. 币种选港币，存款方式选「开通新的 EDDA」。
3. 选你的银行，汇丰是 004；分行代码是银行账号的前三位，账户号码填后面的部分；点一下「存取款指令」，盈透会自动命名。
4. 往下拉，把签名栏右边显示的名字复制进输入框，点确认，再确认一遍账户号码，点继续，等 15 秒左右。

第一次操作，大概率会看到「EDDA 请求被银行拒绝」。原因是开盈透时用的是身份证，开港卡时用的是港澳通行证，两边证件对不上。解决办法：

5. 回到「转账与支付」的存款界面，点刚才被拒绝的那个 eDDA，再点继续，能看到身份文件类型是大陆身份证。
6. 点「上传其他身份证明」，填港澳通行证的号码和到期日，再上传通行证人像面的照片。
7. 页面会说要几个工作日，我实测第二天就审核通过了。再进 eDDA 开通界面，身份文件类型变成港澳通行证，按第 3、4 步重新签名确认，等 15 秒就开通了。

开通之后，在转账界面输入存款金额确认，我入金 100 港币，15 秒左右就到账了。

不想等审核的话，也可以用转数快：在存款方式里拉到最下面选「转数快」，点「如何转账资金」，选银行、填账号和金额后点「获取指令」，盈透会给一个 FPS 识别码。打开汇丰 App，「转账至本地收款人」→ 港元储蓄账户 →「转账至新收款人」→ 选「快速支付系统识别码」，填这个识别码，备注里写上你的盈透账户号码。我实测转数快要二三十分钟才到账，转进去的钱要过几天才能转出。

## 五、eDDA 授权失败怎么办

券商页面上一般只显示「授权失败」或者一串代码，按这个顺序查：

| 失败原因 | 怎么看出来 | 怎么处理 |
| --- | --- | --- |
| 资料和港卡登记的不一致 | 提示户名、证件、账号不符，最常见 | 姓名拼音、证件类型、证件号、账户号码逐项对照港卡 App 里的个人资料重填 |
| 预留手机号不对 | 收不到验证码，或者提示手机号未登记 | 填开港卡时登记的那个手机号；手机号换过的，先在港卡 App 里更新 |
| 券商登记的证件和港卡开户证件不一样 | 盈透等券商用身份证开户、港卡用港澳通行证开，第一次授权被银行拒绝 | 在券商那边补传港澳通行证，审核通过后重新授权；中银香港 App 开的户用港澳通行证被拒的，换成身份证试试 |
| 账户类型选错 | 汇丰只有「港元储蓄」和「港元往来」两个港币账户，券商页面写的是「综合账户」和「港元账户」 | 券商的「综合账户」对应汇丰的港元储蓄，「港元账户」对应港元往来；钱放在港元储蓄的就选综合账户。选错了会从没钱的那个账户扣款，扣款失败还会被收费 |
| 这个账户类型不支持 eDDA | 提示账户类型不支持 | 换成港卡里的储蓄账户，按券商页面的选项选 |
| 银行系统维护 | 提示服务暂时不可用 | 过一段时间再试，深夜和周末银行维护比较多 |
| 授权过期或被取消 | 之前能用，突然扣不了款 | 在港卡 App 里看授权状态，重新授权一次 |

查完还是不行，就联系券商客服，把页面上的错误代码发给他们，他们能查到银行返回的具体原因。

## 六、eDDA 扣款失败怎么办

授权成功之后，每次入金时券商才会真正去扣款。扣款失败最常见的原因只有两个：

- **港卡里的钱不够**：比如钱刚从内地汇出去还没到港卡，就在券商那边点了入金。这时候银行会按「结余不足被退回」收费，中银香港官网收费表写的是每笔 165 港币，社区里也有用户反馈汇丰每次扣 180 港币。有人一天连续失败好几次，月底被扣了 3150 港币。
- **账户类型选错**：钱在汇丰港元储蓄，授权时却选了「港元账户」（对应港元往来），券商去扣的是没钱的那个账户。重新授权，选「综合账户」。
- **金额超过上限**：超过这条 eDDA 授权的上限，或者超过港卡当天的转账限额，银行会拒绝扣款。可以在港卡 App 里把限额调高一点。

所以入金前先打开港卡 App 看一眼余额，确认钱到了再入金；连续失败两次就先停下来查原因，别一直重试。

如果已经被扣了费，可以打港卡的香港客服，说明是第一次遇到、事先不知道会收费，申请退还，不少人都要回来了。具体可以看[汇款到汇丰香港被退回怎么办](./21-汇款到汇丰香港被退回怎么办：RR04、姓名格式、跨境支付通退汇原因和处理方法.md)里的第四部分。

## 七、常见问题

| 问题 | 回答 |
| --- | --- |
| eDDA 安全吗？ | 授权要你本人在券商页面填资料、银行发验证码确认，每次扣款银行都会通知；不想用了可以在港卡 App 里随时取消授权 |
| eDDA 入金要手续费吗？ | 复星用 eDDA 入金不收入金手续费；银行这边扣款成功一般也不收费，只有扣款失败才会收费 |
| eDDA 多久到账？ | 复星交易日一般几分钟到账，盈透我实测 15 秒左右；非交易日提交的，可能要等下一个交易日 |
| 一张港卡能授权给几家券商吗？ | 能，每家券商单独授权一次，互不影响 |
| 转数快转账要手续费吗？ | 个人用转数快转账，香港各家银行一般不收费 |
| 转数快能用内地手机号吗？ | 能。很多港卡开户时登记的就是内地手机号，在港卡 App 里把这个手机号登记到转数快就能用它收款 |
| 虚拟银行支持 eDDA 吗？ | 看券商支持的银行列表。券商 App 里选银行时，列表里有的就能用 |
| 用了 eDDA，还要不要在券商那边填入金凭证？ | 不用，eDDA 是券商直接扣款，自动对上你的账户 |
