# 出入金资金流转从零入门：路径有哪些？底层原理是什么？

对于内地用户跨境投资来说，很多时候最难的可能不是怎么开户怎么投资，而是如何将钱转出去或者转进来，如何丝滑出入金，如何让自己的资产在全球范围内流转。

更具体来说，常见的出入金问题，又被划分为两个领域，一个是美股出入金，另一个是加密货币出入金。

> 当然很多时候，美股和加密货币二者之间又有很多联系，你可能会把稳定币 USDT 转入到美股账户，也可能会把美股账户的钱转入到加密货币账户。

接下来，我们简单总结一下出入金思路，方便大家理解出入金的原理，学习后续对应的具体教程。

## 1. 美股入金路径

常见的美股入金路径为：内地银行换汇 -> [跨境支付通](<../../01-美股投资/01-香港境外银行/07-跨境支付通教程：内地秒级汇款到香港银行账户.md>)汇款到香港银行 -> 香港银行 EDDA 或者 FPS 入金[美股券商](<../../01-美股投资/02-美股券商/README.md>)。

跨境支付通是一个非常好用的南向汇款工具，基本上所有内地银行都可以通过它，秒级汇款到香港银行，不收取任何跨境汇款手续费。

不过它的缺点就是占据每年 5 万美元的外汇额度，额度不够的话可能还需要用到家人的银行账号。

整体来看，从内地向美股券商入金的思路是非常简单清晰的。

## 2. 美股出金路径

美股出金的选择其实相对多样一些。

第一步通常是先从美股券商出金到香港银行，一般没有任何手续费。

当钱进入香港银行之后，就有很多种选择了。

- 比如直接跨境汇款到内地银行，然后在内地银行换汇成人民币。
- 比如使用[熊猫速汇](<02-熊猫速汇教程：港币美元出金回国最详细攻略.md>)，通过对敲的方式，将香港银行的外币转入到内地银行/微信/支付宝账户。
- 比如使用 [Wise](<14-Wise 多币种钱包从 0 到 1 开户-入金-出金教程：轻松玩转 Wise.md>)，将港币转入到 Wise 香港账户，然后再通过 Wise 兑换为人民币，直接转入到内地银行/微信/支付宝账户。
- 当然也可以不做跨境汇款，而是直接在内地消费港币，方式更是五花八门，具体可以参考这篇教程：[港卡的钱怎么在内地花？9 大港币消费方式全解析](<13-港卡的钱怎么在内地花？9 大港币消费方式全解析.md>)

## 3. 加密货币入金路径

最常见的加密货币入金方式，就是通过[币安/欧易交易所的 C2C 路径](<../../02-加密货币/01-交易所/01-大陆用户怎么买比特币？2026 最详细教程（注册到交易全流程）.md>)，和平台商家直接交易，将你手头的人民币换成交易所账户中的 USDT，再通过 USDT，购买比特币/以太坊等等。

只不过在这个过程中，可能会存在风控的问题，毕竟涉及到与陌生人转账。如果入金频率比较高的话，建议不要频繁更换平台的商家，建议使用支付宝入金，多备几个支付宝账号。

至于其它加密货币入金路径，一般都需要用到香港 Visa/万事达卡或者跨境汇款，手续费磨损会高很多，目前主流还是 C2C 入金。

## 4. 加密货币出金路径

加密货币出金路径的选择非常多，最简单最直接的还是 C2C 出金，就是你将手头的 USDT 卖给交易所平台的商家，然后商家把人民币转入到你的账户中，和 C2C 入金是相反的路径。

但是这里需要注意一点，C2C 出金是商家给你转人民币，可能会有收到黑钱的风险，导致你的微信/支付宝/银行卡被冻结，钱无法消费或者取现，解决起来很麻烦。

目前一线交易所（币安/欧易）为了解决这类问题，专门推出了一些冻结赔付计划、严选商家，但还是无法从根本上解决收到黑钱的问题，因为即使 C2C 商家无意作恶，但每天有大量资金经过他们的账户，他们也难以辨别黑钱。

所以很多人在出金 USDT 的时候，不太喜欢用 C2C，而是使用各种中转工具，经过几跳之后，把钱转入到香港银行或者内地账户。

中间可能会用到 [Kraken 海妖交易所](https://www.kraken.com/)、[iFAST 英国银行](<../../01-美股投资/01-香港境外银行/08-英国 iFAST 开户-入金教程：大陆用户从 0 到 1 线上开户入金.md>)、熊猫速汇、Wise、[Neverless](https://neverless.com/) 等等工具。

虽然听起来很复杂、用到的工具很多，但本质原理都是相同的，就是两步走：

- 第一步，将 USDT 通过合规交易所，换为法币美元。
- 第二步，将法币美元跨境汇款到其它境外银行。

至于为什么过程中会涉及到这么多中转工具，本质上还是为了避免被平台风控的问题，毕竟很多平台规定里都明确提过，不接受加密资金，这也意味着如果你这笔钱离加密货币非常近的话，账户也有被风控的可能性。

中转次数越多，资金以及账户就越安全。

一条被很多人跑通且安全的路径就是，币安/欧易 -> Kraken 交易所 -> iFAST -> Wise -> 香港/内地账户。

## 5. 传统金融与加密货币之间的流转

刚才我们讲到的都是美股或者加密自己的出入金方式，但资金流转其实是个非常宽泛的概念。

美股属于传统金融，你也可以将美股的钱转入到加密账户，也可以将加密账户的钱转入到美股。

中间过程中，最关键的桥梁就是香港银行。

所以说，想要顺利完成出入金资金流转的话，[香港银行账户](<../../01-美股投资/01-香港境外银行/README.md>)是必不可少的，这也是跨境投资的第一步。
