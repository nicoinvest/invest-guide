# 出入金 / 资金流转

资金流转主线下的二级分类入口：先解决账户之间的出入金，再按需办理海外电话卡，用于接收银行、券商和平台的验证码。

## 二级分类

| 顺序 | 分类 | 主要内容 | 进入 |
| --- | --- | --- | --- |
| 01 | 出入金 | 跨境汇款、币种兑换、资金转入与转出 | [进入](./01-出入金/README.md) |
| 02 | 海外电话卡 | 办理渠道、实名充值与接收验证码 | [进入](./02-海外电话卡/README.md) |
