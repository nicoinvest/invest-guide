# 港卡之间怎么互转：汇丰转众安、众安转汇丰，转数快 FPS ID 每一步怎么填，限额、到账时间和美元怎么转

作者：[Nico 投资有道](https://www.youtube.com/@NicoGrowthz) · [投资导航网页版](https://invest-nav.com/tutorials/hk-banks/text/hk-bank-to-bank-transfer/) · [返回本分类](./README.md)

港卡开了两三张，钱怎么从一张转到另一张？转数快填手机号、邮箱还是 FPS ID？明明是转给自己，为什么钱又回到了原来那张卡？汇丰提示「转账至非登记受款人的每日限额剩余 0 元」是什么意思？港币能秒到，美元又该怎么转？

很多朋友是在出入金的时候遇到这个问题：券商出金到了汇丰，想转去众安换汇或者回内地；或者众安的钱要转去汇丰，再入金嘉信、复星。

今天这篇教程，我会把港卡之间互转一次性讲清楚：用我实际操作的汇丰转众安、众安转汇丰两组截图，带你走一遍每一步怎么填，避开转给自己却转错卡、被限额卡住这些常见的坑，最后再告诉大家整个过程中需要注意的事项。

那我们话不多说，尽快开始今天的内容。

## 结论速览（2026 年 10 月核对）

- **港币互转首选转数快（FPS）**：香港各家银行之间 24 小时实时到账，个人转账不收手续费。我实测汇丰转众安、众安转汇丰，都是同一分钟到账，汇丰页面显示费用「获豁免」。
- **转给自己，用 FPS ID 最稳**：FPS ID 是每家银行账户各自的一串数字，填它一定转到那个账户。用手机号转的话，钱会进这个手机号设了「预设」的那家银行，手机号在几家银行都登记过，就可能转回原来那张卡。
- **先查收款银行的 FPS ID**：众安在「我的」→「转数快和转账设置」→「我的转数快」；汇丰在头像 →「转账及缴费」→「注册转数快或查看注册信息」。
- **汇丰转给新收款人，先看限额**：没登记过的收款人走「小额转账」，我这个账户每日上限是 1 万港币。要转更多，在「管理转账限额」里调高，或者先把收款人登记好。
- **众安转出限额**：转账页面会显示「今日可转出限额」，在「转数快和转账设置」→「限额设置」里调。
- **美元不能走转数快**：转数快只支持港币和人民币。美元要用收款账号做本地银行转账，汇丰、中银香港网上转美元不收费，一般当天到账。
- **只转本人名下的账户**：本人账户之间转账最简单，收款人姓名会显示成你的英文名，部分用星号隐藏。

## 二、汇丰转众安：每一步怎么操作

### 第一步：在众安 App 里查自己的 FPS ID

1. 打开众安银行 App，点左上角头像进入「我的」，点「转数快和转账设置」。
2. 点「我的转数快」。
3. 页面上能看到你在众安登记过的手机号、邮箱和 FPS ID，后面写着「预设收款银行 ZA Bank」。把 FPS ID 这串数字记下来。

- **图 1**：众安「我的」页面，点「转数快和转账设置」。
- **图 2**：点「我的转数快」；下面的「限额设置」是调转出限额的地方。
- **图 3**：「我的转数快」里能看到已登记的手机号、邮箱和 FPS ID，以及预设收款银行。

![图 1 至图 3：众安银行 App 查自己的转数快 ID：我的、转数快和转账设置、我的转数快里看 FPS ID 和预设收款银行](https://invest-nav.com/tutorial-content/new-2026-10-26/hk-bank-to-bank-transfer/steps-01.webp)

### 第二步：在汇丰 App 里转账

1. 打开 HSBC HK App，点上方的「转账」，再点「本地受款人／"转数快"」。
2. 支账户选「港元储蓄」。汇丰 One 的港元往来、港元储蓄、外币账户共用一个账号，转港币要选有钱的港元账户。
3. 进入受款人列表，点最上面的「转账至新受款人」。
4. 收款方式选「快速支付系统识别码」，也就是 FPS ID，填刚才在众安查到的那串数字，点「下一步」。
5. 页面会自动带出受款人的英文姓名，部分用星号隐藏，核对是不是你自己。想下次少填一步，可以打开「添加至受款人名单」。

- **图 4**：汇丰「转账」页面，点「本地受款人／"转数快"」。
- **图 5**：支账户选「汇丰 One 港元储蓄」。
- **图 6**：受款人列表最上面点「转账至新受款人」。
- **图 7**：收款方式选「快速支付系统识别码」，输入众安的 FPS ID。
- **图 8**：系统自动带出受款人姓名，核对是本人再点「继续」。

![图 4 至图 8：汇丰香港 App 用转数快转给众安：本地受款人转数快、支账户选港元储蓄、转账至新受款人、选快速支付系统识别码、自动带出受款人姓名](https://invest-nav.com/tutorial-content/new-2026-10-26/hk-bank-to-bank-transfer/steps-02.webp)

### 第三步：输入金额，确认

1. 输入金额。金额下面会显示两行限额：「转账至非登记受款人的每日限额」和「小额转账每日限额」。我这里第一行剩 0 元，第二行剩 1 万港币，所以这笔是按小额转账走的。
2. 备注和给受款人的信息都是选填，转给自己可以不填。点「继续」。
3. 核对资料页上，再看一遍支账户、入账账户、金额，费用显示「获豁免」，转账日期是「即时」。点「确认」。
4. 页面显示「转账已成功入账」，下面有参考编号，可以点右上角分享图标保存。
5. 打开众安 App，首页「动态」里就能看到这笔钱，和汇丰提交是同一分钟。

- **图 10**：核对资料，费用获豁免，即时转账。
- **图 11**：转账已成功入账。

## 三、众安转汇丰：每一步怎么操作

### 第一步：在汇丰 App 里查自己的 FPS ID

1. 打开 HSBC HK App，点左上角头像进入「个人档案」，点「转账及缴费」。
2. 点「注册"转数快"或查看注册信息」。
3. 页面上列着你用手机号、邮箱和「快速支付系统识别码」注册的情况。记下快速支付系统识别码那串数字。

注意看手机号后面写的是「已注册，预设账户」还是只写「已注册」。写着「预设账户」的，别人用这个手机号给你转钱，就会进汇丰。

- **图 13**：汇丰「个人档案」里点「转账及缴费」。
- **图 14**：点「注册"转数快"或查看注册信息」。
- **图 15**：看到快速支付系统识别码，也就是汇丰这边的 FPS ID。

![图 13 至图 15：汇丰香港 App 查自己的转数快 ID：个人档案、转账及缴费、注册转数快或查看注册信息里的快速支付系统识别码](https://invest-nav.com/tutorial-content/new-2026-10-26/hk-bank-to-bank-transfer/steps-04.webp)

### 第二步：在众安 App 里转账

1. 打开众安 App，首页点「转出」。
2. 在搜索框里输入汇丰的 FPS ID，下面会匹配出收款人，姓名部分隐藏，核对一下点进去。
3. 输入金额，类型选「即时」。页面会显示「可用活期余额」和「今日可转出限额」。
4. 备注选填。确认没问题，把底部的「右滑完成转账」滑到底。

- **图 16**：众安「转出」里输入汇丰的 FPS ID，匹配到收款人。
- **图 17**：输入金额，类型选「即时」，右滑完成转账。

![图 16 至图 17：众安银行 App 用转数快转给汇丰：转出里输入 FPS ID 匹配收款人，输入金额选即时，右滑完成转账](https://invest-nav.com/tutorial-content/new-2026-10-26/hk-bank-to-bank-transfer/steps-05.webp)

众安的类型里还有「预设」和「定期」：预设是指定某一天转，定期是按周期自动转，比如每个月固定转一笔去券商那张卡。

## 四、为什么转给自己要用 FPS ID，不用手机号

转数快的手机号和邮箱，一个号码可以在好几家银行登记，但只能有一家是「预设」。别人用手机号给你转钱，钱会进预设的那家。

所以，用手机号转给自己会出现这种情况：

- 你的手机号在汇丰和众安都登记了，预设是汇丰。
- 你在汇丰 App 里用自己的手机号转账，想转去众安。
- 钱最后进的是预设银行汇丰，等于自己转给了自己的同一张卡。

FPS ID 不一样，它是每家银行账户单独生成的一串数字，填哪个 ID，钱就进哪个账户。转给自己的其他港卡，用 FPS ID 最不容易出错。

用手机号也可以，前提是先确认这个手机号的预设银行就是你想收钱的那家。从内地用跨境支付通往港卡汇钱，用的就是手机号，所以要把常用的那张港卡设成预设，具体可以看[开完港卡先做的 7 件事](<./20-开完港卡先做的 7 件事：转数快、转账限额、海外提款、Apple Pay、电子月结单一次设好.md>)。

## 五、美元怎么在港卡之间转

转数快只支持港币和人民币，**美元不能走转数快**。美元要用收款账号做本地银行转账：

1. 在收款银行 App 里找到美元账户的账号。汇丰的港币、美元共用一个账号；中银香港的美元在外汇宝（多币种）账户里，账号和港币储蓄账户不一样。
2. 在转出银行 App 里选「本地转账」或「转账至其他本地银行」，转出账户选美元账户，填收款银行和账号，币种选美元。
3. 收款人姓名照收款银行登记的英文名填。

费用方面，MoneyHero 2026 年 10 月整理的收费是：汇丰、中银香港网上转美元到其他本地银行不收费，截数时间都是营业日下午 5 点 45 分；渣打每笔 22 美元，Mox 每笔 20 美元。转之前在 App 的核对页面看一眼费用。

如果美元是要入金券商，直接从有美元的那张港卡转到券商，不用先在港卡之间倒一手。入金的步骤可以看[盈透入金教程](<../02-美股券商/27-盈透证券入金教程：港卡用 eDDA、转数快、电汇怎么入金，存款通知每一栏怎么填，入金没到账怎么办.md>)和[复星入金出金教程](../02-美股券商/24-复星证券入金和出金教程：eDDA、转数快、网银转账怎么入金，港币美元怎么出金到港卡，每一步怎么填和常见问题.md)。

## 六、整个过程中需要注意的事项

1. **先小额试一笔**。第一次转一张新卡，先转 100 港币，确认到账再转大额。
2. **核对自动带出的姓名**。转数快会显示收款人的英文名，部分用星号隐藏，对不上就别转。
3. **转给自己用 FPS ID**。手机号会进预设银行，容易转回原卡。
4. **汇丰新收款人有小额限额**。没登记的收款人每日 1 万港币以内，要转更多就先调限额或者登记收款人。
5. **众安看「今日可转出限额」**。不够就去「限额设置」里调。
6. **美元走本地转账**。转数快转不了美元。
7. **支账户选对币种**。汇丰同一个账号下有港元往来、港元储蓄和外币账户，选有钱的那个。
8. **保存转账记录**。成功页面的参考编号截个图，万一没到账可以拿去问银行。
