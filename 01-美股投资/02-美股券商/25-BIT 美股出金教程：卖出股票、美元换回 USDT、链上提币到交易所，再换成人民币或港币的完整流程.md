# BIT 美股出金教程：卖出股票、美元换回 USDT、链上提币到交易所，再换成人民币或港币的完整流程

作者：[Nico 投资有道](https://www.youtube.com/@NicoGrowthz) · [投资导航网页版](https://invest-nav.com/tutorials/us-brokers/text/bit-us-stock-withdrawal/) · [返回本分类](./README.md)

BIT 美股赚了钱之后，怎么把钱拿出来？股票卖了，为什么钱划不出去？美元换回 USDT 还是 USDC？提币选哪条链最省钱？USDT 到了交易所之后，又怎么换成人民币或者港币？手续费磨损是多少？到账时间多久？

入金的时候，USDT 几分钟就到账了，很多朋友觉得 BIT 很丝滑。但出金要比入金多走几步：卖出股票要等结算，美元要先换回稳定币，提币之前要先设好通行密钥，链和地址一步都不能错。

今天这篇教程，我会把 BIT 美股出金从卖出股票到钱回到你手里的每一步一次性讲清楚，带你避开这些常见的坑，最后再告诉大家整个过程中需要注意的事项。

那我们话不多说，尽快开始今天的内容。

## 结论速览（2026 年 10 月核对）

- **出金一共四步**：卖出股票、等结算 → 证券账户划回 BIT 主账户，同时把美元换成 USDT 或 USDC → 链上提币到交易所或钱包 → 在交易所换成人民币或港币。
- **卖出之后要等结算**：美股是 T+1 结算，卖出后下一个交易日钱才能划出证券账户。
- **美元换回稳定币**：活动期间，证券账户划回主账户、美元换成 USDC 是 1:1 无损的，快速到账服务费也免收。换成 USDT 可能因为汇率有一点点偏差。
- **想在交易所 C2C 卖成人民币，就换 USDT**。欧易、币安的 C2C 主要是 USDT 交易，换成 USDC 到了交易所还要再换一次。
- **提币之前先设好通行密钥**：BIT 提币要用通行密钥验证，路径是首页左上角头像 →「账户安全」→「通行密钥」。
- **提币网络选 Arbitrum**：手续费低，入金时也是用这条链。BIT 帮助中心写的 USDT-TRC20 提币费是 1 USDT，USDT-ERC20 是 8 USDT；有用户实测 Arbitrum 和 BEP20 是 0.5 USDT。
- **到账很快**：划转一般 1 分钟内到主账户，链上提币一般几分钟到交易所。
- **奖励留存期内别急着出金**：BIT 的入金奖励要求入金后留存 30 天，出金会让累计净入金变少，可能拿不到奖励。

## 一、出金整体路线

先把整条路线看清楚，再一步步操作：

1. **在美股账户卖出股票**，等 T+1 结算完成。
2. **资金划转**：把美元从 BIT 证券账户划回 BIT 主账户，划转的时候选择换成 USDT 或 USDC。
3. **链上提币**：从 BIT 主账户把 USDT 提到你在欧易、币安这些交易所的充值地址，或者你自己的钱包。
4. **换成法币**：在交易所用 C2C 卖成人民币，或者走复星虚拟资产账户换成港币出到港卡。

## 二、出金之前先做好两件事

### 1. 设置通行密钥

BIT 链上提币需要用通行密钥（Passkey）验证。没设置的话，走到提币最后一步会卡住。

设置路径：打开 BIT App，点首页左上角的头像 →「账户安全」→「通行密钥」，按提示用面容 ID 或指纹创建一个。

### 2. 在交易所拿到充值地址

以欧易为例：打开欧易 App，点「充币」，搜索 USDT，网络选 **Arbitrum One**，复制充值地址。

记住两件事：

- **网络要和 BIT 提币时选的一致**。这里选 Arbitrum One，BIT 那边就选 Arbitrum。
- **地址用复制粘贴**，不要手动输入。

还没有交易所账户的话，先看[大陆用户买比特币教程](<../../02-加密货币/01-交易所/01-大陆用户怎么买比特币？2026 最详细教程（注册到交易全流程）.md>)，里面有欧易、币安的注册和身份认证步骤。

## 三、第一步：卖出股票，等结算

在 BIT 的美股界面，找到要卖的股票，点「交易」→ 卖出，选限价单或市价单，输入数量，确认。

卖出之后，钱不会马上就能划走。美股从 2024 年 5 月 28 日起是 **T+1 结算**，也就是成交后的下一个交易日才完成交割。结算完成之前，这笔钱可以继续买股票，但划不出证券账户。

举个例子：周五美股盘中卖出，要等到下周一结算完成才能划转；遇上美股休市，还要再往后顺延。

卖出的费用：BIT 免佣金，平台费每股 0.005 美元、每笔最低 0.99 美元；卖出时另收交易活动费用和美国证监会费用，金额都很小。

## 四、第二步：证券账户划回主账户，美元换成 USDT

结算完成之后，进入 BIT App 的「美股」→「资产」→「资金划转」，选择从证券账户划到主账户。

划转的时候，在「选择转账方向」里选美元换成哪种稳定币：

| 换成 | 适合谁 | 说明 |
| --- | --- | --- |
| **USDT** | 要在欧易、币安 C2C 卖成人民币 | 交易所 C2C 主要是 USDT，到账后可以直接卖；因为汇率波动，可能有一点点偏差 |
| **USDC** | 继续持有稳定币，或者转到支持 USDC 的平台 | 活动期间 1:1 无损兑换 |

费用方面：

- **兑换费**：活动期间美元换 USDC 免费、1:1 兑换；社区里有用户反馈，平时的费率是 0.05%。
- **快速到账服务**：日常收 0.1%，2026 年 10 月核对时活动期间免收。
- **快速档和普通档**：划转分快速和普通两档。有用户反馈，下午经常只剩普通档，要等一天左右才到账。急用钱的话，尽量上午操作。

确认之后，一般 1 分钟以内就能在 BIT 主账户的钱包里看到 USDT 或 USDC。

## 五、第三步：链上提币到交易所

1. 在 BIT App 点「钱包」→「转出」→「链上提币」。
2. 币种选 USDT（和上一步换成的币种一致）。
3. 网络选 **Arbitrum**，和交易所充值页面选的一致。
4. 把交易所的充值地址粘贴进来，核对前四位和后四位。
5. 输入提币数量。页面上会显示这笔的手续费和实际到账数量，提交前看一眼。
6. 点「提币」，用通行密钥完成验证。

一般几分钟就能在交易所的资金账户里看到这笔 USDT。

各网络的提币手续费：

| 网络 | 提币手续费 | 说明 |
| --- | --- | --- |
| Arbitrum | 0.5 USDT 左右（用户实测） | 最推荐，便宜，入金也用这条链 |
| BEP20 | 0.5 USDT 左右（用户实测） | 也便宜，交易所充值要选 BSC／BEP20 |
| TRC20 | 1 USDT（BIT 帮助中心） | 交易所普遍支持 |
| ERC20 | 8 USDT（BIT 帮助中心） | 最贵，不推荐 |

**第一次提币先小额测试**，比如先提 10 USDT，到账了再提大额。

## 六、第四步：USDT 换成人民币或港币

USDT 到了交易所之后，怎么变成能花的钱？下面这几条路，按你的需要选：

| 路线 | 最后拿到 | 适合谁 | 教程 |
| --- | --- | --- | --- |
| 欧易、币安 C2C 卖出 USDT | 人民币，进支付宝、微信或银行卡 | 想直接换成人民币，金额不大 | [大陆用户买比特币教程](<../../02-加密货币/01-交易所/01-大陆用户怎么买比特币？2026 最详细教程（注册到交易全流程）.md>)（C2C 卖出是买入的反向操作） |
| 复星虚拟资产账户 | 港币或美元，提到本人港卡 | 有港卡，金额比较大，想走持牌机构 | [复星虚拟资产账户教程](<../../03-出入金与资金流转/01-出入金/12-复星虚拟资产账户教程：大额出入金 USDT + 投资港美股.md>) |
| Bybit Card + 香港支付宝 | 人民币，进大陆支付宝 | 小额、想少走 C2C | [Bybit Card + 香港支付宝出金](<../../03-出入金与资金流转/01-出入金/04-Bybit Card + 香港支付宝出金 USDT 教程：大陆用户实操.md>) |
| Kraken 换英镑出金到 iFAST | 英镑，再转 Wise | 已经有 iFAST、Wise | [Kraken 出金到 iFAST](<../../02-加密货币/01-交易所/04-Kraken 海妖交易所出金教程：USDT 换英镑出金到 iFAST，再转 Wise（2026 实测）.md>) |

C2C 卖出 USDT 的时候，注意这几点：

- 在 C2C 页面切到「出售」，选 USDT，优先选成交量大、完成率高的商家。
- 卖出之后，一定要在自己的支付宝、微信或银行卡里**确认收到了钱、金额对得上**，再点「放行」。没收到钱千万别放行，有问题直接在交易所里申诉。
- 收款账户要和交易所实名一致，只用本人名下的账户收款。

这套流程只适用于个人同名账户之间的资金流转，不涉及非同名账户转账，更不涉及违法洗钱的操作，请大家务必遵守平台规则以及相关地区的法律法规。

## 七、BIT 能不能直接出美元到银行卡？

BIT 官网写明，除了 USDT、USDC 出入金，也支持美元电汇。但电汇要走 SWIFT 和中转行，时间要几个工作日，还可能被中转行扣费。

以 BIT 港股账户为例，帮助中心写的港币电汇出金每笔收 250 港币，最低出金 1250 港币，收款行和中转行的费用另算。

所以对大部分朋友来说，**换成 USDT 链上提币**是最快、最便宜的出金方式。

## 八、整个过程中需要注意的事项

1. **结算完成之前划不出钱**。卖出后要等 T+1，周五卖出要等下周一，遇上美股休市再顺延。
2. **划转时选对币种**。要去 C2C 卖成人民币就换 USDT；换成了 USDC，到了交易所还要再换一次。
3. **网络一定要一致**。BIT 提币选 Arbitrum，交易所充值也要选 Arbitrum One。选错网络，钱可能永远找不回来。
4. **地址用复制粘贴，第一次先小额测试**。
5. **提前设好通行密钥**，不然提币最后一步会卡住。
6. **只用本人名下的账户**。从 BIT 提到你自己实名的交易所账户，C2C 收款也用本人账户。
7. **奖励留存期内别急着出金**。BIT 的开户活动要求开户后 14 天内入金达标、留存 30 天。出金会让累计净入金变少，跌破档位的话，那一档的 30 天留存要重新计算。
8. **下午划转可能变慢**。快速档用完之后只剩普通档，要一天左右，急用钱尽量上午操作。

## 九、常见问题

| 问题 | 回答 |
| --- | --- |
| 股票卖了，为什么钱划不出去？ | 美股是 T+1 结算，卖出后下一个交易日结算完成，才能从证券账户划出去 |
| 美元换回 USDT 要手续费吗？ | 活动期间划转免费，美元换 USDC 是 1:1；换 USDT 可能因为汇率有一点点偏差。社区里有用户反馈，平时美元换 USDC 的费率是 0.05% |
| 换 USDT 还是 USDC？ | 要在欧易、币安 C2C 卖成人民币，换 USDT；只是继续持有稳定币，USDC 也可以 |
| 提币选哪条链？ | 选 Arbitrum，手续费 0.5 USDT 左右；ERC20 要 8 USDT，最贵 |
| 提币要多久到账？ | 划转一般 1 分钟内到主账户，链上提币一般几分钟到交易所 |
| 提币时要验证什么？ | 用通行密钥验证。没设置的话，先在首页左上角头像 →「账户安全」→「通行密钥」里创建 |
| 选错网络了怎么办？ | 先别再转第二笔，马上联系 BIT 和收款交易所的客服，提供提币记录。能不能找回要看两边平台，很可能找不回来，所以提币前一定要核对网络 |
| 可以直接提到内地银行卡吗？ | 不能。BIT 出金是 USDT、USDC 链上提币或美元电汇，要换成人民币，得先到交易所 C2C 卖出，或者走复星虚拟资产账户出到港卡 |
| 出金会影响入金奖励吗？ | 会。奖励按累计净入金算，也就是入金减去出金，留存期内出金可能拿不到对应档位的奖励 |
| BIT 能出美元到港卡吗？ | 官网写明支持美元电汇，但要走 SWIFT 和中转行，时间长、可能被扣费；港股账户港币电汇出金每笔收 250 港币 |
