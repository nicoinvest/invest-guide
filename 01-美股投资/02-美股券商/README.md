# 美股券商怎么选？开户门槛、功能、费率与出入金路径

> 为什么建议大陆用户优先开通美股券商，以及 QDII 基金、美股券商、美股代币化三种投资方式的对比，已经在 [美股投资](../README.md) 一级分类的导读里讲过，这里不再重复。
>
> 本篇只解决两个问题：**钱怎么进出美股券商**，以及**在目前还能开户的券商里，怎么挑一家适合自己的**。

## 1. 美股券商的出入金路径

出入金是大陆用户使用美股券商时最先遇到、也最容易被卡住的一环。整条路径可以概括为一句话：**入金是把钱先送到香港银行，再从香港银行转入美股券商；出金则反过来走一遍。**

### 1.1 入金：大陆银行 → 香港银行 → 美股券商

1. **在内地银行换汇**。把人民币换成港币或者美元，会占用每人每年 5 万美元的结售汇额度。
2. **跨境汇款到香港银行**。目前最主流的方式是跨境支付通，直接在内地银行 App 上操作，汇款到自己的香港银行账户，基本秒级到账。此外还有熊猫速汇、Wise 等方式可选。
3. **从香港银行入金到美股券商**。通过转数快（FPS）、EDDA 授权或者银证转账，把港币或美元从香港银行账户转入券商账户。
4. **到账后在券商 App 内交易**。资金到账即可下单买入美股、ETF 或债券。

也就是说，绝大多数美股券商不支持内地银行账户直接入金，中间必须有一个境外银行账户做中转。对大陆用户来说，最主流、成本最低的选择就是香港银行账户——可以直接去香港线下免费开户。开户流程、银行选择和各家的具体操作，整理在 [香港境外银行](../01-香港境外银行/README.md) 分类下。

汇款这一步的具体操作，可以参考 [跨境支付通教程：内地秒级汇款到香港银行账户](<../01-香港境外银行/07-跨境支付通教程：内地秒级汇款到香港银行账户.md>)。

### 1.2 出金：美股券商 → 香港银行 → 内地

出金就是把上面的流程反向执行：

1. **从券商提款到香港银行**。在券商 App 里发起提款，资金回到绑定的香港银行账户。
2. **从香港银行把钱转回内地**。常见的做法有三类：一是跨境汇款回内地银行账户；二是用香港银行卡在内地直接消费或取现，不占用结汇额度；三是通过香港支付宝、微信香港钱包等渠道在内地使用。

这三类方案的手续费、到账速度、是否占用外汇额度都不一样，具体教程整理在 [出入金 / 资金流转](../../03-出入金与资金流转/01-出入金/README.md) 分类下。

### 1.3 例外：不用香港银行也能入金

有一部分券商支持用稳定币 USDT 或 USDC 直接入金，不需要香港银行账户，整个流程在 App 内即可完成。对于客观条件上没办法前往香港开户的朋友，这是目前最直接的替代方案。因为走的是加密资产的通道，这类入金通常还会和加密货币交易所、虚拟卡等工具配合使用，相关教程也一并整理在本分类和资金流转分类里。

## 3. 常见问题

**Q：大陆用户投资美股合法吗？**

通过正规渠道投资美股是合法的，关键是资金来源合法、走正规渠道。

**Q：CRS 税务信息交换会影响我吗？**

CRS 是信息交换机制，不等于直接收税。目前小资金用户没啥问题。但长期来看，合规申报是趋势。建议认真填写 W-8BEN 等税务表格，保留好投资记录。

**Q：港资券商和美国本土券商，CRS 有什么区别？**

香港参与 CRS，会向大陆税务机关交换账户信息。美国不参与 CRS，但有自己的 FATCA 体系。如果你通过盈透开的是美国账户（Interactive Brokers LLC），理论上不会通过 CRS 交换给中国。但这不意味着完全没有税务风险。

**Q：现在还能开盈透吗？**

越来越难了。盈透近期对大陆用户的审核明显收紧，要求提供海外居住证明等材料。如果你没有海外身份，建议优先考虑复星或致富。
