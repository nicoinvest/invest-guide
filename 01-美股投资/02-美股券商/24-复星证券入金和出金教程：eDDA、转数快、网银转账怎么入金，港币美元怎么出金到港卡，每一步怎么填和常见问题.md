# 复星证券入金和出金教程：eDDA、转数快、网银转账怎么入金，港币美元怎么出金到港卡，每一步怎么填和常见问题

复星证券开户成功之后，钱到底怎么转进去？eDDA、转数快、网银转账有什么区别，该选哪一个？港卡里的美元能不能直接存进去？赚了钱之后怎么出金回港卡？手续费是多少？到账要多久？

开户的完整步骤，我在[复星证券开户教程](./01-复星证券开户教程：大陆用户无门槛开户免佣.md)里已经演示过了。但真正用起来，很多朋友是卡在入金和出金这一步：eDDA 授权一直失败，美元转过去了却迟迟没到账，第一次出美元又被要求补月结单。

今天这篇教程，我会把复星的入金和出金一次性讲清楚：每种入金方式怎么操作、每一栏怎么填，出金到港卡的每一步，带你避开这些常见的坑，最后再告诉大家整个过程中需要注意的事项。

那我们话不多说，尽快开始今天的内容。

## 结论速览（2026 年 10 月核对）

- **复星支持存三种币**：港币、美元和离岸人民币。入金和出金都只能用本人名下的银行账户，别人代付的钱会被退回。
- **港币入金首选 eDDA**：在星财富 App 里授权一次港卡，之后每次入金复星自动从港卡扣款，交易日一般几分钟到账，没有入金手续费。
- **eDDA 授权用什么证件**：汇丰选港澳通行证；中银香港、众安一般选内地身份证。证件号码和手机号要和开港卡时登记的一致。
- **美元入金走网银转账**：在 App 里复制复星的美元收款账户，从港卡转过去，再回 App 点「已转账，通知收款」，上传转账截图。不通知的话，钱可能在收款账户里放好几天。
- **港币换美元**：在 App 里点「货币兑换」，按实时汇率换，有一点点汇差，一般一分钟左右到账。
- **出金**：「账户」→「提取资金」→ 选币种和收款账户 → 输入金额 → 短信验证。交易日提交，一般下一个工作日之内到账，周末和节假日不处理。
- **第一次出美元要先认证收款账户**：上传这张港卡的月结单，审核通过之后才能出金。
- **出金手续费**：美元出金到汇丰香港没有手续费；出到中银香港等其他银行，可能被中转行扣几美元，有用户实测扣了 3 美元左右。
- **领奖励期间别急着出金**：开户奖励按净入金算，也就是入金减去出金，出金之后可能就不达标了。

## 一、入金之前先准备好这几样

1. **一张本人名下的港卡**。汇丰、中银香港、众安、蚂蚁这几家都可以，还没有港卡的话，可以先看[众安银行开户教程](<../01-香港境外银行/01-众安银行开户教程：大陆用户线上从 0 到 1 开户.md>)。
2. **港卡的账户号码**。注意是账户号码，不是卡号，在港卡 App 的账户详情里能看到。中银香港的港币储蓄账户和外汇宝（多币种）账户是两个不同的号码，入港币要用港币储蓄账户；汇丰所有币种共用一个账户号码。
3. **一张带姓名和账户号码的截图或月结单**。绑定银行账户的时候要上传，汇丰可以直接截 App 里的个人档案页面，中银香港可以在 App 的「电子结单或通知书」里找到月结单。上传原图，不要裁剪、不要打码。
4. **开港卡时登记的证件和手机号**。eDDA 授权要用，必须和银行记录完全一致。

## 二、港币入金：eDDA 授权（最推荐）

eDDA 可以理解为「授权复星从你的港卡扣款」。授权一次之后，每次入金只要在复星 App 里输入金额，钱就会自动从港卡划过来，不用再打开银行 App 转账。

### 1. 添加香港银行账户

打开星财富 App，点下方的「账户」，再点「存入资金」，选择存入港币，然后点「添加银行账户」→「香港银行账户」。

每一栏这样填：

| 栏目 | 怎么填 |
| --- | --- |
| 银行 | 选你的港卡银行，汇丰是 004，中银香港是 012，众安是 387 |
| 姓名 | 拼音，姓在前、名在后，和港卡上的英文名一致 |
| 账户类型 | 汇丰选综合账户；中银香港选港币储蓄账户 |
| 账户号码 | 只填数字，不要带横杠和空格 |
| 银行账户凭证 | 上传带姓名和账户号码的截图或月结单 |

### 2. 授权 eDDA

银行账户添加好之后，点「授权开通」eDDA，选择证件类型，输入证件号码和开港卡时登记的手机号，提交。

证件类型这样选：

| 港卡银行 | eDDA 授权用的证件 |
| --- | --- |
| 汇丰香港 | 港澳通行证 |
| 中银香港 | 内地身份证 |
| 众安银行 | 内地身份证 |
| 其他银行 | 一般先选内地身份证，失败了再换港澳通行证试一次 |

关键就一条：**选开港卡时用的那个证件**。你开港卡时登记的是哪个证件，这里就选哪个。

App 会提示授权需要一个工作日，实际上一般几分钟到半小时就通过了。

### 3. 发起入金

授权通过之后，重新进入「存入资金」，上方会显示 eDDA 已授权。点「立即入金」，输入金额，点「存入」。

交易日一般几分钟就能在账户里看到这笔钱。

### 4. eDDA 入金要注意的三件事

- **港卡里的钱要够**。余额不够的时候发起 eDDA，扣款会失败，有用户反馈汇丰因此收了一笔 165 港币的手续费。第一次被扣的话，可以联系银行客服申请退回。
- **注意港卡的单日限额**。eDDA 扣款也受港卡的转账限额限制，超过了会失败。大额入金之前，先在港卡 App 里把限额调高，或者分几天入金。
- **复星的 eDDA 一般用来存港币**。想存美元，走下面的网银转账。

## 三、美元入金：网银转账 + 通知收款

港卡里本来就有美元，不想换成港币再换回来，就用网银转账直接存美元。

### 1. 拿到复星的美元收款账户

在「存入资金」里选择存入美元，选「网银转账」，页面会显示复星的收款账户信息，收款银行有汇丰、渣打、恒生几家。

**你的港卡是汇丰，就选汇丰的收款账户**，汇丰转汇丰是行内转账，最快也最省钱。

### 2. 在港卡 App 里转账

以汇丰为例：打开 HSBC HK App，点「转账」→「本地受款人／转数快」，转出账户选你的汇丰美元储蓄账户，转账给新受款人，把复星页面上的收款账户名称和账户号码复制粘贴进去。

**备注栏填你的星财号**，在星财富 App「我的」页面、账户名字下面能看到。

用中银香港转的话，转出账户要选外汇宝里的美元账户，收款银行选汇丰（004）。

转账成功之后，**马上截图保存转账记录**，截图里要能看到转账时间、你的姓名、收款账号和金额。

### 3. 回复星 App 通知收款

回到星财富 App，点「已转账，通知收款」，填写实际转账的美元金额，选择转出的银行账户，上传刚才的截图，提交。

这一步千万别漏。不发起入金通知的话，你的钱可能会在复星的收款账户里放好几天，迟迟到不了你的证券账户。

到账时间一般 1 到 2 个工作日，有用户周日转账、周一上午提交通知，几分钟就入账了。

## 四、其他入金方式

### 1. 转数快（FPS）

「存入资金」里也可以选转数快，复制页面上复星的转数快 ID，在港卡 App 里用转数快转过去，转完同样要回 App 通知收款、上传截图。

转数快适合偶尔入一笔、不想授权 eDDA 的朋友。经常入金的话，还是 eDDA 最省事。

### 2. 用 USDT 入金

手里是 USDT 的话，可以走复星的虚拟资产账户：USDT 充值进去，换成港币或美元，再划转到证券账户。开通条件和完整步骤，看[复星虚拟资产账户教程](<../../03-出入金与资金流转/01-出入金/12-复星虚拟资产账户教程：大额出入金 USDT + 投资港美股.md>)。

### 3. 内地银行能不能直接汇款给复星

不建议。社区里有用户反馈，从内地银行直接电汇到复星的收款账户会被拒绝。先把钱汇到自己的港卡，再从港卡入金复星，是最稳的路线，内地电汇到港卡怎么填可以看[内地银行电汇到港卡](../../03-出入金与资金流转/01-出入金/23-内地银行电汇到港卡怎么填：收款人姓名、账号、SWIFT、收款行地址、中转行和手续费承担方式一次讲清.md)。

## 五、港币怎么换成美元

存进去的是港币，想买美股，要先换成美元。

在星财富 App 的账户页面点「货币兑换」，选择从港币换成美元，输入金额，确认。用的是实时汇率，会有一点点汇差，有用户实测 500 港币换到 63.67 美元，当时的实时汇率能换 63.78 美元。换好的美元一般一分钟左右就能看到。

反过来，美元出金之前想换回港币，也是在这里操作。

## 六、出金到港卡：每一步怎么操作

### 1. 出金步骤

1. 打开星财富 App，点「账户」→「全部功能」，在「更多」页面的「资金」一栏里点「提取资金」。
2. 「币种」选出金的币种：港币、美元或离岸人民币。
3. 「账户」选钱所在的账户：卖出股票的钱在「综合账户 - 证券」，放在现金通里的钱选「综合账户 - 现金通」。
4. 「收款银行」选本人名下、已经绑定的银行账户；还没绑过的，先按第二部分添加。
5. 输入出金金额。下面的「现金可提」就是现在能提的金额，刚卖出股票的钱要等结算完成才能提；「到账时间」会显示预计哪天汇出。
6. 点「确定提取」，在弹出的「提取确认」里核对收款账户和金额，点「确定」。要求输入短信验证码的话，填上就行。
7. 看到「提交成功」就提交好了。想看进度，点「提取记录」，或者在「更多」页面点「资金记录」；状态还是「处理中」的时候，可以点「撤回」取消这笔出金。

### 2. 第一次出美元：先认证收款账户

第一次往一个账户出美元，App 会提示要先认证这个收款账户：上传这张港卡最近的月结单，月结单上要能看到你的姓名、账户号码和美元账户。

有用户实测，提交之后 3 个小时左右就审核通过了。认证通过一次，之后出美元就不用再传了。

### 3. 到账时间

- 交易日提交，一般下一个工作日之内到账。有用户周一傍晚提交美元出金，周二下午到账。
- 中午 12:00 之前确认的出金当天处理，12:00 之后的顺延到下一个工作日。
- 当天新加的银行账户，要到第二个工作日审批之后才处理出金。
- 周末和香港公众假期提交的，要等下一个交易日才处理。
- 急用钱的话，尽量在交易日中午 12:00 之前提交，收款银行也提前一天绑好。

### 4. 出金手续费

- **美元出金到汇丰香港**：没有手续费，全额到账。
- **美元出金到中银香港等其他银行**：可能被中转行扣几美元，有用户实测出到中银香港扣了 3 美元左右；出到恒生、渣打实测没有损耗。
- **港币出金**：港币在香港本地清算，一般不经过中转行。

所以，**想出美元，最省钱的组合就是复星 + 汇丰香港**。

## 七、整个过程中需要注意的事项

1. **只用本人名下的账户**。入金的港卡、出金的收款账户，户名都要和复星账户一致。别人代付的钱会被原路退回，还可能产生退款手续费。
2. **转账截图要完整**。网银转账、转数快入金的截图，要能看到你的姓名、收款账号、金额和时间，不要裁剪、不要打码，否则复星对不上账。
3. **领奖励期间先别出金**。开户奖励一般按净入金算，也就是入金减去出金。奖励发放之前就出金，净入金可能就不达标了。具体的档位和持有天数，开户时在活动页面上看一眼。
4. **港卡限额提前调好**。eDDA 和转账都受港卡的单日限额限制，大额入金之前先在港卡 App 里调高。
5. **港卡资料变了，复星这边也要改**。港卡换了账户、通行证换了新证，eDDA 可能会失效，要在复星 App 里重新绑定、重新授权。
6. **港币回到港卡之后怎么回内地**，可以看[港币出金回国怎么选](<../../03-出入金与资金流转/01-出入金/20-港币出金回国怎么选：众安、蚂蚁、大象（天星）、BOC Pay、熊猫速汇、中银快汇 6 种方式对比.md>)。

## 八、常见问题

| 问题 | 回答 |
| --- | --- |
| eDDA 授权一直失败怎么办？ | 先核对三样：证件类型是不是开港卡时用的那个、证件号码有没有输错、手机号是不是开港卡时登记的号码。汇丰选港澳通行证，中银香港和众安一般选内地身份证；都对还是失败，联系港卡银行客服问一下 |
| eDDA 能存美元吗？ | 一般用来存港币。存美元走网银转账，再在 App 里通知收款 |
| 美元转过去了，为什么还没到账？ | 最常见的原因是没有在 App 里点「已转账，通知收款」。补上通知、上传截图，一般 1 到 2 个工作日到账 |
| 转账备注忘了填星财号怎么办？ | 尽快在 App 里通知收款、上传截图，复星可以按截图对账；还是没到账就联系复星客服 |
| 中银香港的港币和美元账户号码不一样？ | 对。中银香港的港币储蓄账户和外汇宝账户是两个号码，eDDA 入港币用港币储蓄账户，转美元用外汇宝里的美元账户 |
| 复星出金多久到账？ | 交易日提交，一般下一个工作日之内到账；周末和节假日不处理 |
| 复星出金要手续费吗？ | 美元出金到汇丰香港没有手续费；出到中银香港等其他银行，可能被中转行扣几美元 |
| 第一次出美元为什么要传月结单？ | 复星要先认证这个收款账户是你本人的。上传带姓名、账户号码的月结单，审核通过之后才能出金，之后就不用再传了 |
| 刚卖出股票的钱能马上出金吗？ | 要等结算完成，美股一般是成交后下一个交易日，「提取资金」页面上会显示可提取的金额 |
| 可以出金到内地银行卡吗？ | 不建议。先出到本人港卡，再用众安、BOC Pay、熊猫速汇这些方式[转回内地](<../../03-出入金与资金流转/01-出入金/26-美股券商的钱怎么转回内地？嘉信、盈透、复星、盈立、BIT 出金回国路线对比：到哪张卡、手续费多少、多久到账、占不占外汇额度.md>) |
