# 中概股和 ADR 是什么？阿里巴巴、京东、拼多多在美股买的是什么，ADR 换算比例、存托费、退市风险，和港股买哪个好

作者：[Nico 投资有道](https://www.youtube.com/@NicoGrowthz) · [投资导航网页版](https://invest-nav.com/tutorials/us-basics/text/china-adr-guide/) · [返回本分类](./README.md)

在美股买阿里巴巴、京东、拼多多，买到的到底是什么？为什么阿里巴巴美股股价和港股股价对不上？中概股的退市风险现在还在吗？同一家公司，美股和港股应该买哪个？

很多朋友开了美股账户之后，第一批买的就是自己熟悉的中国公司。但中概股在美股的交易方式和美国公司不太一样，背后有 ADR、VIE、双重上市这些概念，不搞清楚的话，看股价、算成本、拿分红都容易出错。

今天这篇教程，我会把中概股和 ADR 一次性讲清楚，告诉大家投资中概股需要注意的事项。

那我们话不多说，尽快开始今天的内容。

## 一、中概股是什么？

**中概股**是「中国概念股」的简称，一般指**业务主要在中国、但在海外上市的公司**，最常说的是在美股上市的这一批：

| 公司 | 美股代码 |
| --- | --- |
| 阿里巴巴 | BABA |
| 拼多多 | PDD |
| 京东 | JD |
| 百度 | BIDU |
| 网易 | NTES |
| 携程 | TCOM |
| 蔚来 | NIO |
| 理想汽车 | LI |
| 小鹏汽车 | XPEV |

这些公司在美股交易的，大部分不是普通股票，而是 **ADR**。

## 二、ADR 是什么？

ADR 的全称是 **American Depositary Receipt，美国存托凭证**。

外国公司想在美国上市，直接把本国股票拿到美国交易很麻烦，于是找一家美国的**存托银行**：

1. 公司把一部分普通股交给存托银行保管；
2. 存托银行按一定比例，在美国发行对应的 ADR；
3. 投资者在美股买卖 ADR，就相当于间接持有这家公司的股票。

![ADR 是怎么来的：外国公司把普通股交给存托银行保管，存托银行按比例发行 ADR 在美股交易，投资者买卖 ADR 就相当于间接持有公司股票，分红由存托银行转发](https://invest-nav.com/tutorial-content/new-2026-11-10/china-adr-guide/fig-01.webp)

对投资者来说，**ADR 的交易方式和普通美股完全一样**：用美元交易、同样的交易时间、同样可以用限价单下单。

ADR 不只中国公司在用，台积电（TSM）、阿斯麦（ASML）、诺和诺德（NVO）这些外国公司在美股交易的，也是 ADR。

## 三、ADR 的换算比例

**1 份 ADR 不一定等于 1 股普通股**，每家公司的比例不一样：

| 公司 | 1 份美股 ADR 对应 |
| --- | --- |
| 阿里巴巴 BABA | 8 股普通股 |
| 百度 BIDU | 8 股 A 类普通股 |
| 拼多多 PDD | 4 股 A 类普通股 |
| 京东 JD | 2 股 A 类普通股 |
| 台积电 TSM | 5 股普通股 |

这就解释了为什么阿里巴巴的美股价格和港股价格对不上：**美股 1 份 ADR = 8 股港股**，再考虑美元和港币的汇率，两边的价格其实是接近的。

举个例子：

- 阿里巴巴港股股价 100 港币；
- 美股 ADR 理论价格 ≈ 100 × 8 ÷ 7.8（港币兑美元汇率）≈ 102.6 美元。

实际交易时会有一点点偏差，但不会差太多，否则就会有人套利。

换算比例可能会调整，最准确的是看公司年报，或者券商 App 里个股资料页的说明。

## 四、ADR 的存托费

存托银行替你保管股票、转发分红，会收一笔**存托费**（ADR Fee），一般是每份 ADR **每年 1 到 5 美分**。

收取方式通常是：

- 有分红的公司，直接从分红里扣；
- 没有分红的公司，由券商从你的账户现金里扣。

金额不大，但第一次在账户流水里看到一笔莫名其妙的「ADR Fee」时，不用担心，这是正常的。

### 分红扣税

外国公司 ADR 的分红，**一般不按美国的 10% 或 30% 扣股息税**，而是按公司所在国家或地区的规则扣。美国公司分红的扣税规则，可以看[美股要交哪些税](<./11-买美股要交哪些税？分红扣 10% 还是 30%、卖出赚钱交不交税、W-8BEN 和 1042-S 税单，以及国内境外所得怎么申报.md>)。

## 五、VIE 结构：中概股特有的风险

很多中概股还有一层特殊的结构，叫 **VIE**（可变利益实体）。

因为中国对互联网、教育等行业的外资持股有限制，这些公司的做法是：

1. 在开曼群岛等地注册一家上市公司，就是你在美股买的那家；
2. 上市公司在中国设立外资子公司；
3. 外资子公司通过**一系列协议**（而不是股权）控制实际运营业务的国内公司，并拿走它的利润。

![VIE 结构：投资者持有的是开曼上市公司的 ADR，上市公司通过外资子公司，用协议控制国内实际运营的公司，而不是直接持股](https://invest-nav.com/tutorial-content/new-2026-11-10/china-adr-guide/fig-02.webp)

也就是说，**投资者持有的是一家离岸公司的股份，它对国内业务的控制靠的是合同**。平时这没什么问题，但这是投资中概股时需要知道的一层额外风险，公司的年报里一般都会专门写出来。

## 六、退市风险：来龙去脉

前几年中概股经常传出「要被退市」，这件事的经过是：

| 时间 | 事件 |
| --- | --- |
| 2020 年 12 月 | 美国通过《外国公司问责法》：连续几年不让美国监管机构检查审计底稿的公司，要被禁止在美国交易 |
| 2022 年 | 一批中概股陆续被列入「预摘牌名单」，中概股大跌 |
| 2022 年 8 月 | 中美监管机构签署审计监管合作协议 |
| 2022 年 12 月 | 美国监管机构宣布已经能够完整检查审计底稿，撤销了对中国内地和香港审计机构的认定 |

目前这个风险已经大大缓解，但**它取决于两国监管合作能不能持续**，以后如果关系变化，类似的担忧还可能再出现。

这也是很多中概股选择**回香港二次上市或双重主要上市**的原因之一。

## 七、美股和港股，买哪个？

阿里巴巴（9988）、京东（9618）、百度（9888）、网易（9999）、携程（9961）等公司，都已经在港股上市，同一家公司可以在两边买。拼多多目前只在美股上市。

| | 美股 ADR | 港股 |
| --- | --- | --- |
| 交易时间 | 北京时间晚上 | 北京时间白天 |
| 交易货币 | 美元 | 港币 |
| 最小交易单位 | 1 份 ADR，部分券商支持碎股 | 每手股数由公司定，一手可能要几千港币 |
| 交易成本 | 很多券商佣金很低，没有印花税 | 有股票印花税（双边各 0.1%）和交易费 |
| 退市风险 | 受中美监管关系影响 | 基本不受影响 |
| 存托费 | 有 | 没有 |

### 两边能不能互相转换？

对于已经在港股上市的公司，**美股 ADR 和港股普通股一般可以互相转换**，通过券商申请，存托银行办理，会收一定费用，需要几个工作日。2022 年中概股退市担忧最严重的时候，不少投资者就是这样把美股 ADR 转成了港股。

### 怎么选？

- 账户里本来就是美元、习惯晚上交易，买美股 ADR 很方便；
- 担心监管风险，或者希望白天交易，可以选港股；
- 买的金额不大的话，美股 ADR 可以买碎股，比港股一手的门槛低。

如果你更想买一篮子中国公司，可以看看中概互联网 ETF，在[美国以外的市场怎么买](<../04-美股ETF/17-美国以外的市场怎么买？VXUS、VEA、VWO、KWEB 全球、发达、新兴市场和中概 ETF 对比.md>)里有介绍。

## 写在最后

中概股和 ADR 就记这几点：

1. **在美股买中概股，买的一般是 ADR**，交易方式和美股一样；
2. **ADR 和普通股有换算比例**，阿里巴巴 1 份 ADR = 8 股，看价格时要换算；
3. **ADR 每年有少量存托费**，分红扣税按公司所在地的规则；
4. **很多中概股是 VIE 结构**，退市风险在 2022 年底已经缓解，但和中美监管关系有关；
5. **阿里、京东、百度等在港股也能买**，美股 ADR 和港股可以互相转换。
