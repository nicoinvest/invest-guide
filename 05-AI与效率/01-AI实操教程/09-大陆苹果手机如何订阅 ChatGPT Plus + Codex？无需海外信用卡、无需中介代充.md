## 七、订阅常见问题

| 遇到的问题 | 常见原因 | 处理办法 |
| --- | --- | --- |
| 礼品卡兑换失败 | 礼品卡和 Apple ID 不是同一个国家或地区 | 换成和 Apple ID 同地区的礼品卡 |
| 点升级后提示地址无效 | 美区 Apple ID 还没有填账单地址 | 按提示补填账单地址 |
| 余额有 20 美元却扣款失败 | 账单地址所在的州要另外收销售税，余额不够 | 多充一点余额 |
| 新号充值后被锁，或者要求验证 | 新注册的 Apple ID 一上来就充值，容易触发风控 | 先正常下载使用几个免费 App，过一段时间再充值 |
| 电脑网页端显示的还是免费版 | 网页登录的账号和手机上订阅的不是同一个 | 用订阅时同一个登录方式和邮箱登录 |
| Codex 额度不够用 | 不同套餐的额度不同 | 在 Codex 的用量页面查看剩余额度 |
