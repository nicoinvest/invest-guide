## 五、Claude 防封指南

1️⃣ 检查国内/国外/Google 访问 IP 的一致性

登陆 Claude 账号之前，先通过 https://www.ip111.cn 检测你的IP地址。

如果 3 个地址指向的是同一地址，则说明 IP 没问题。

2️⃣ 检查你的 IP 风险度

进入 https://scamalytics.com，检测你的 IP 风险度。如果欺诈评分是 0，则代表 IP 基本没有风险，可以使用。

3️⃣ 不要频繁切换 IP、切换浏览器、切换设备

尽可能使用同一地区的 IP，比如日本、美国、新加坡；

尽可能使用同一个浏览器，比如 Google Chrome，因为大多数人都是注册 gmail 邮箱账号，搭配 Chrome 更方便；

尽可能使用电脑访问 Claude。不过目前我订阅 Claude 有几个月，重度高频使用 Claude 也有两周多，电脑手机都有在用，暂时没有出现封号的情况。

防封号的根本还是在于使用纯净的 IP。
