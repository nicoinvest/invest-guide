# 我用 Claude Code 搭了一支 Agent 团队：一个人做自媒体和投资的 AI 工作流

作者：[Nico 投资有道](https://www.youtube.com/@NicoGrowthz) · [投资导航网页版](https://invest-nav.com/tutorials/ai-insights/text/my-ai-agent-content-workflow/) · [返回本分类](./README.md)

经常听到一个说法：Claude Code 是做给程序员用的东西。

都已经到了 2026 年，还是有很多人抱着这种看法。我自己就是程序员出身，听到这句话其实挺无奈的。它的名字里虽然带着 Code，但早就不只是写代码的工具了，与其说是 vibe coding，不如说是 vibe working。

现在我一个人做 YouTube、写推文、运营网站和社群，同时还要做自己的投资。能同时把这么多事情转起来，很大程度上靠的是我用 Claude Code 搭出来的几个 Agent。

今天这篇文章，我就把我自己的 AI 工作流从 0 到 1 讲一遍：我为什么从 OpenClaw 换到了 Claude Code，一个 Agent 到底需要什么，我的 Agent 每天在帮我做哪些事，以及中间踩过的几个坑。

## 一、先走了一段弯路：从 OpenClaw 换到 Claude Code

OpenClaw 火起来的那段时间，我也第一时间用它搭了一个 Agent。

OpenClaw 最大的优势是开箱即用，配置简单，对完全不会写代码的人非常友好。但我用了一段时间之后，发现小毛病不断：要么日报卡住发不过来，要么 API 被限流，要么 token 浪费得太多。

后来我静下来想了想：我真的需要 OpenClaw 吗？

我当时的需求其实很简单，就是让 Agent 每天帮我汇总一下市场信息，再个性化地辅助我做内容。这种需求，用不着大动干戈。我完全可以用 Claude Code 自己定义一个专属的 Agent，项目文件就在我电脑上，Agent 的每一个细节我都看得到、改得了。

所以我的结论是：**对于大多数人来说，OpenClaw 开箱即用的那些功能其实是冗余的，反而容易让人忽略 Agent 最本质的意义：帮你完成重复性的工作，提高你的生产力。**

## 二、一个极简版 Agent，只需要四样东西

很多人一听到 Agent 就觉得很复杂。但在我看来，一个极简版 Agent，核心就四样东西：

- **soul（灵魂）**：你是谁？你的性格、风格、价值观是什么样的。
- **skills（技能）**：你能做什么？搜索、写代码、调 API、查财报等等。
- **memory（记忆）**：你记得什么？对话的上下文，或者存在外部的长期记忆。
- **scheduler（调度）**：你什么时候该做什么事？也就是定时任务和工作流程。

把这四样东西用大白话描述清楚，发给 Claude Code，它十分钟以内就能帮你把整个 Agent 项目的框架搭出来。剩下的就是你不断验收、反馈、优化。

具体怎么一步步搭，我写在了[Claude Agent 搭建教程](<../01-AI实操教程/02-Claude Agent 搭建教程：20 分钟零基础打造专属 AI Agent 助手.md>)里，跟着做二十分钟就能有一个能用的 Agent。

## 三、Agent 真正的燃料，是你自己的数据

框架人人都能搭，Prompt 人人都会写，真正拉开差距的，是数据。

### 1. 第一份日报，像一个财经小编写的

我的 Agent 刚配置好的第二天，就产出了第一份财经日报。说实话，整体还是差点意思，读起来像是财经新闻小编写出来的东西，完全没有我自己的投资风格。

比如在比特币的部分，它给了一堆中短线交易信号。但我对比特币的想法其实很简单，就是 DCA 定投囤币，不会去做额外的短线操作。这样的建议，对我来说没有任何用。

问题出在哪？**它根本不了解我。**

### 2. 把 6000 多条推文塞给它之后

后来我花了几十分钟，把过去写过的 6000 多条推文，全部交给 Claude Code，让它总结出我的「人格」。

它最后输出了一个 markdown 文件，里面涉及到我的投资观念、写作风格、市场观点、过往经历，甚至还包括我的三观，以及我对整个世界怎么运转的理解。过去两年我脑子里的想法，都被汇总成了一份人格画像。

看完之后，我的感觉是：AI 比我自己还要懂我。

我又把最近一个月关于美股和比特币的思考，也全部喂给了 Agent。从这之后，它产出的东西才慢慢开始有用了。

### 3. 记录下来的每一个字，都是数字资产

这件事也让我意识到，这一两年做自媒体最大的价值是什么：**沉淀下来了上百万字的想法、观点、思考和踩坑经历。**

在 AI 爆发之前，我自己都觉得记笔记、写推文是个不起眼的小习惯，很多东西几年都不会回看一次。结果到了 Agent 爆发的这一刻，这些数据全部派上了用场，让我能在几十分钟之内，搭出一个真正懂我的数字分身。

反过来看，OpenClaw 那波热潮退去之后，很多人发现 token 烧了一大堆，钱也花了不少，最后搭出来的 Agent 只是一个能简单聊聊天的玩具。缺的不是框架，甚至不是最顶尖的大模型，而是个性化的数据。

你脑子里的做事逻辑、判断标准、行业经验、踩过的坑，这些东西是你独有的，也是 Agent 真正需要的燃料。所以我一直建议大家尽早打造自己的知识库，我现在把临时灵感、投资研究、写过的推文、视频稿、教程和网站开发记录，都分门别类地放进了 Obsidian。

## 四、我的 Agent 现在每天在帮我做什么

我现在最常用的这个 Agent，可以简单理解成我的投研助理，它主要在帮我做这几件事：

**1. 每天定时产出财经日报。**每天早上，Agent 会自动去全网检索过去一天的宏观新闻、美股大盘动态，以及我关注和持仓的个股动态，过滤掉噪音，把真正值得关注的内容整理成一份日报发给我。看完之后，我大概就知道过去 24 小时世界发生了什么、美股为什么涨为什么跌、我的持仓有没有好的加仓机会。

**2. 监控美股和比特币的抄底信号。**它会帮我盯着市场，留意有没有到我提前定好的加仓区间。

**3. 辅助投资决策。**当我在考虑某个操作的时候，我会让 Agent 从我自己的投资逻辑出发，把收益和风险尽可能详细地列出来。因为它足够了解我，给出来的东西不是通用的废话，而是符合我个人投资风格的判断。当然，最后拍板的永远是我自己。

**4. 辅助内容创作。**帮我筛选最近比较热门的话题，帮我想选题、理大纲，帮我检查错别字。

**5. 运营电报群。**我把 Agent 接进了电报群，做成了一个机器人，可以随时回答群友的问题。只要是我频道里讲过的内容，美股投资、办港卡、出入金，它基本都能回答个八九不离十，而且说话的风格和我很像。接入方法可以看[Claude Code 接入 Telegram 官方插件教程](<../01-AI实操教程/03-Claude Code 接入 Telegram 官方插件教程：从 0 到 1 配置.md>)。

成本方面，我刚开始用 Claude API 跑的时候算过一笔账：一天跑 4 个定时任务，总共花了不到 1 美元。按我的使用频率，每个月的成本基本能控制在 100 美元以内，比我预期的低很多。

## 五、给自己搭一个 6 人 Agent 开发团队

除了投研助理，我还给自己的网站搭了一支 Agent 开发团队。

这个网站从一开始就是我想做的自己的产品。X 毕竟是公开的社交平台，哪天账号出了问题，辛辛苦苦写的几千字教程可能就再也搜不到了，网站的掌控权则百分之百在自己手里。而在 Coding Agent 爆发之后，网站的代码基本都不需要我自己写了，我负责提想法、提 bug，剩下的流程全部由 AI 执行。

但几个月 vibe coding 下来，我也有两个很心累的痛点：一是 Claude 经常没法完全理解我的需求，二是它有时候思考推理的时间太短。这两点都会导致最后做出来的效果，和我的预期出入很大。

想来想去，还是得从源头解决。于是我花了几个小时，搭了一个 6 人 Agent 开发团队：**产品经理、架构师、UI 交互设计、前端开发、后端开发、测试**，我自己当总指挥。

从 0 到 1 开发一个新功能的时候，这个团队会先做需求分析、竞品调研、视觉交互方案和前后端的开发方案。等我确认方案没问题之后，几个 Agent 再各自分工，一起把需求做完。

一个人当老板，手下一整支团队，这种感觉真的很上瘾，这大概就是创造的魅力。

## 六、AI 在我的自媒体工作流里，到底做了多少

现在我做 YouTube 的整个流程里，大概 70% 以上的工作是 AI 接管执行的，我主要负责指挥。

- **找灵感**：我以前一直把灵感随手记在手机备忘录里，很多一段时间不看就忘了。迁移到 Obsidian 之后，我用 Claudian 插件让 Claude 把以前的内容整体汇总了一遍，一下子整理出了 110 个灵感。
- **做调研**：教程里涉及到的产品背景、注意事项，基本都交给 AI。比如做 Saily 美国手机号教程时收不到验证码，我就让 Codex 去翻官网文档和中文社区的用户反馈找原因，比自己找能省下九成时间。
- **写稿子**：这一步 AI 参与得最少。视频稿大部分是我自己手写的，推文更是基本全靠自己，AI 只在我卡住的时候帮忙理一理逻辑。
- **录制**：从来不用 AI 配音，一直是我自己的声音。

为什么写稿这一步我坚持自己来？因为我试过让 AI 模仿我的风格写教程，改了很多版也写不像。而且我觉得，大家愿意长期看一个人的内容，是因为连接和信任。这部分我专门写了一篇：[AI 时代，「说人话」反而成了最稀缺的能力](<./03-AI 时代，「说人话」反而成了最稀缺的能力：我用 AI 写内容的两条红线.md>)。

**执行交给 AI，判断和表达留给自己**，这是我目前觉得最舒服的分工。

## 七、一次让我愣住的对话

前段时间，我在纠结要不要给频道改名。

因为我现在聊的东西早就不止是投资了，还有 AI、加密、资金流转，几乎所有和钱有关的东西。所以我想换一个更大众一点、带 Money 的英文名。

我把这个想法和顾虑一起丢给了 Claude，让它帮我权衡一下。说实话我的预期不高，觉得它顶多列几条优缺点，给一些和稀泥的建议。

结果它的回答让我直接愣住了。它先把我的顾虑详细拆了一遍，然后提了几个我完全没想到的角度：这个名字在中文语境里，容易让人联想到「搞钱割韭菜」；英文名容易水土不服，新观众看到之后，未必知道这是一个中文频道。

它还反问我：你聊 AI 是从投资的视角在聊，港卡和出入金本质上是全球资产配置，教程最后也是在服务投资，这些真的超出了「投资有道」的范围吗？「道」这个字本身就可以撑得很宽。

最后它建议我不要改名。我想了想，确实太有道理了。

整个回答读下来，我并不觉得 Claude 比我聪明，而是觉得它好像比我更了解我自己的处境。它不是在套模板，而是会指出我的思维盲区，从不同角度提出反对意见。

**2026 年的 AI，已经不只是一个回答问题的工具了，而是能真正帮你一起做决策的助理。**而它之所以能做到，前提还是第三部分说的：它有足够多关于我的上下文。

## 八、普通人怎么开始

如果你看到这里，也想给自己搭一个 Agent，我的建议是这几步：

1. **先订阅一个最好的大模型。**每个月 20 美元订阅 Claude，大陆用户的开通方法可以看[订阅 Claude 教程](<../01-AI实操教程/01-大陆用户订阅 Claude AI 大模型教程：无门槛从 0 到 1 开通.md>)。
2. **从一个最小的需求开始。**比如每天一份只关于你持仓的日报，不要一上来就想搭一个什么都能干的超级助理。
3. **先把你的数据整理出来。**笔记、推文、文章、聊天记录里的思考，越多越好，这是 Agent 能不能真正懂你的关键。
4. **把它当成一个新员工来带。**刚开始它什么都不懂，需要你耐心地手把手教。每一次反馈和修正，最后都会变成它的长期记忆，直到它熟悉你的所有偏好、能独当一面。

## 九、写在最后

2026 年的 AI 工具，门槛已经低到你只要会打字、会说话、能把需求讲清楚，就能用 Claude Code 干绝大多数的白领工作。

归根到底，这不是能力的差距，而是认知的差距。**认知差就是红利差**：当你还觉得 Claude Code 是程序员的玩具，别人已经在用它提高生产力、赚钱了。

当一个 Agent 真正成为你的数字员工之后，即使你不工作，它也在持续为你创造复利。这才是 AI 时代真正有价值的数字资产。
