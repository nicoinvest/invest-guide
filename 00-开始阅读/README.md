# 开始阅读

这份指南按「一级分类 + 二级分类」整理 Nico 的投资教程。你可以按照主线顺序阅读，也可以从具体问题进入。

## 如何选择起点

- **第一次接触美股**：先在「美股投资」下了解香港境外银行和美股券商，按需阅读「出入金 / 资金流转」，再学习美股 ETF；暂时不开境外账户的，可以先看美股 QDII 基金。
- **第一次接触加密货币**：先读「加密货币基础」理解概念并保管好钱包，再按需查交易所和虚拟卡教程。
- **已有账户**：直接进入对应二级分类，先核对文章适用条件、所需材料与更新时间。

基础概念类内容（常见名词、费用与风险）会编入各二级分类的开头部分，不再单独设「投资基础」章节。

## 如何使用目录

文件夹前的数字表示顺序：一级分类在前，二级分类在其下。每个分类中的 README 是目录，具体教程整理后会按数字编号排列。
