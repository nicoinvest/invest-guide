# 开始阅读

这份指南按主题整理 Nico 的投资教程。你可以按照章节顺序阅读，也可以从具体问题进入。

## 如何选择起点

- **第一次接触美股**：先看投资基础，再了解券商。银行与出入金章节可根据所选账户的需要阅读。
- **第一次接触加密货币**：先理解基本概念，再阅读钱包与账户安全，随后查找需要的操作教程。
- **已有账户**：直接进入相关分类，先核对文章适用条件、所需材料与更新时间。

## 如何使用目录

文件夹前的数字表示章节顺序。每个分类中的 README 是目录，具体教程整理后会按数字编号排列。
