## 项目介绍

大家好，我是 Nico。

想开始投资美股或了解加密货币，很多人首先遇到的，是一连串具体问题：银行账户怎么准备？券商怎么选？资金怎样转入、转出？看教程时碰到的账户、费用和操作名词，又分别是什么意思？

这个项目用来整理我写过的投资教程，涵盖香港银行、美股券商、出入金、美股与 ETF、加密货币、钱包与账户安全。内容按主题和阅读顺序编排，你可以从基础开始，也可以直接查找眼下需要解决的问题。

如果你喜欢网站阅读，可以前往 [投资导航](https://invest-nav.com/)；喜欢跟着视频学习，可以看我的 [YouTube 频道](https://www.youtube.com/@NicoGrowthz)。

> 当前进度：项目首页和分类目录已建立，教程正文正在整理。各分类页提供网站已有内容的入口，仓库内的文章会逐篇补齐。

## 从这里开始

第一次阅读，先打开 [开始阅读](./00-开始阅读/README.md)，了解这份指南的使用方式。

| 你的目标 | 建议阅读顺序 |
| --- | --- |
| 从零了解美股投资 | 投资基础 → 美股券商 → 按需阅读香港银行与出入金 → 美股与 ETF |
| 从零了解加密货币 | 投资基础 → 加密货币基础 → 钱包与账户安全 → 按需阅读操作教程 |
| 已经有账户，寻找具体步骤 | 直接进入对应分类，核对教程的适用条件和更新时间 |

这是阅读顺序。具体账户、材料和操作步骤，以所选教程说明的条件为准。
